SLICING PATTERNS
أنماط التقسيم الشائعة
text[:n]
First n characters
"Python"[:3] → "Pyt"
text[-n:]
Last n characters
"Python"[-3:] → "hon"
text[::2]
Every 2nd character
"Python"[::2] → "Pto"
text[::-1]
Reversed string
"Python"[::-1] → "nohtyP"
💡 These patterns are used everywhere — file extensions, palindromes, masking, and more!
