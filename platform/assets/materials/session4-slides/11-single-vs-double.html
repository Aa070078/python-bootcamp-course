SINGLE VS DOUBLE QUOTES
العلامات المفردة مقابلة المزدوجة
Double Quotes "...":
main.py 
# Great when text has apostrophes
msg1 = "It's beautiful"
msg2 = "Don't stop"
msg3 = "She's here"
Single Quotes '...':
main.py 
# Great when text has double quotes
msg4 = 'He said "hi"'
msg5 = 'Use "quotes" here'
msg6 = 'She whispered "stop"'
✓ Both produce identical string objects — pick whichever avoids escaping
