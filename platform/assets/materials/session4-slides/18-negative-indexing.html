print(word[-1])   # n  (last char)
print(word[-2])   # o  (2nd to last)
print(word[-6])   # P  (first char)
Negative Index Map:
-1 = last character
-len(s) = first character
✓ Pro tip: word[-1] is the easiest way to get the last character!
