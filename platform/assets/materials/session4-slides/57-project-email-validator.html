PROJECT 2 // EMAIL VALIDATOR
مشروع 2 — محقق البريد الإلكتروني
Check if an email is valid
✉️ Contains @ symbol
🌐 Ends with .com
🚫 No spaces in the email
📏 Length is at least 5 characters
main.py 
email = "user@example.com"
valid = True

if " " in email:
    valid = False
    print("❌ No spaces allowed")
if "@" not in email:
    valid = False
    print("❌ Missing @ symbol")
if not email.endswith(".com"):
    valid = False
    print("❌ Must end with .com")
if len(email) < 5:
    valid = False
    print("❌ Too short")

if valid:
    print("✅ Valid email!")
💡 Uses multiple validation checks — each one can catch a different error!
