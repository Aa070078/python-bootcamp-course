Score password strength from 0 to 4
+1 Minimum 8 characters
+1 Contains at least one digit
+1 Contains at least one uppercase letter
+1 Contains at least one lowercase letter
main.py 
password = "MyPass123"
strength = 0

if len(password) >= 8:
    strength += 1
if any(c.isdigit() for c in password):
    strength += 1
if any(c.isupper() for c in password):
    strength += 1
if any(c.islower() for c in password):
    strength += 1

if strength == 4:
    print("🔒 Strong password!")
elif strength >= 2:
    print("⚠️ Medium strength")
else:
    print("❌ Weak password!")
💡 The any() function returns True if at least one item in the iterable is True
