🧠 SCOPE — WHERE VARIABLES LIVE
Local vs Global 🔍
المتغير المحلي يعيش داخل الدالة، والعالمي يعيش خارجها في أعلى البرنامج
🌍 Global
Defined at the top level — visible to everything below it.
x = 10 # global
📦 Local
Defined inside a function — visible only inside it.
def f(): y = 5 # local
Lookup order: local first → then global.
