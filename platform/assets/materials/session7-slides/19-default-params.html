🔧 DEFAULT PARAMETERS
Optional inputs 🎚️
القيمة الافتراضية: معامل اختياري — إن لم تُمرّر، تُستخدم القيمة الجاهزة
What it is
A parameter with a fallback value. If the caller skips it, Python uses the default.
def greet(name, greeting="Hello"):
Golden rule ⚠️
Defaults must come AFTER required parameters.
# ❌ def f(a=1, b):
# ✅ def f(a, b=1):
Think: settings menu ⚙️ — you only change what you need, the rest has sane defaults.
مثل إعدادات التطبيق: غيّر ما تحتاجه فقط، والباقي له قيم جاهزة منطقية
