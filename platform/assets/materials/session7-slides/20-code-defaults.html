Greet with or without a greeting
استدعِ الدالة مع أو بدون القيمة الثانية — كلاهما صحيح
defaults.py
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")
 
greet("Nour") # uses default
greet("Nour", "Salam") # overrides it
greet("Nour", "Ahlan") # another option
Output
Hello, Nour!
Salam, Nour!
Ahlan, Nour!
