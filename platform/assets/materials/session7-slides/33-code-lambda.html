Sort by any key 🔑
رتّب قائمة الطلاب حسب العمر باستخدام lambda
lambda_sort.py
double = lambda x: x * 2
print(double(5)) # 10
 
students = [("Nour", 19), ("Omar", 21), ("Sara", 18)]
students.sort(key=lambda s: s[1]) # sort by age
print(students)
Output
10
[('Sara', 18), ('Nour', 19), ('Omar', 21)]
