🏗️ REUSABLE FUNCTIONS & DESIGN
Design like a pro ✨
اسم الدالة فعل واضح، ومهمة واحدة لكل دالة، ومواصفات واضحة
Naming rules 📛
✅ snake_case
✅ verbs: get_total, is_even, find_max
❌ vague: thing, x1, do_stuff
One job per function 🎯
If the name needs "and", split it:
calculate_and_print → two functions.
Small functions compose into big programs 🧱
Reusable = parameterized 📦: same machine, different ingredients, predictable results.
