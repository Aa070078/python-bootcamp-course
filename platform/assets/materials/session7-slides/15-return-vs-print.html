💥 RETURN vs PRINT
The showdown 🥊
return تُعيد القيمة للمستدعي، أما print فتعرضها على الشاشة فقط
🖥️ print
Shows text on the screen.
👀 For humans. The value is then GONE.
🎁 return
Hands a value BACK to the caller.
🤖 For your code. It can be stored and reused.
rule of thumb: a function's JOB is to return — printing is a side effect. 🔎
القاعدة: وظيفة الدالة أن تُعيد قيمة، والطباعة مجرد أثر جانبي
