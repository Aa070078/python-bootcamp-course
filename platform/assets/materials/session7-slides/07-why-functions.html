🎯 WHY FUNCTIONS EXIST
A function is a named recipe 📋
الدالة وصفة مسماة: اكتب الخطوات مرة واحدة ثم استدعِها متى شئت
🔥 Reuse
Write once, call 1000 times. Fix a bug once — it's fixed everywhere.
🧩 Organize
Break a big program into small, named pieces — like chapters in a book.
🐞 Debug once
One small function is easy to test. Whole programs are scary to test.
📤 Abstract
Hide the how; focus on the what. Callers don't need the recipe details.
🔑 Golden rule: a function should do ONE thing, and do it WELL.
