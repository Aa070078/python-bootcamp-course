📦 PARAMETERS vs ARGUMENTS
Two words, one idea
المُعامِل هو صندوق جاهز في التعريف، والحجة هي القيمة التي تضعها فيه
🎫
Parameter
The placeholder written in the definition. Like an empty textbox on a form.
def greet(name): # name = parameter
🎁
Argument
The actual value you pass when calling. It fills the placeholder.
greet("Nour") # "Nour" = argument
Remember the form 📝
The form has empty fields (parameters). You fill them with your info (arguments).
المُعامِلات حقول فارغة في استمارة، والحِجَج هي المعلومات التي تملأ بها الحقول
