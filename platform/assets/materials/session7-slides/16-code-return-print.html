شاهد الفرق: الدالة التي تُعيد تسمح لك بمواصلة الحساب
return_vs_print.py
def show_add(a, b):
    print(a + b) # only prints
 
def real_add(a, b):
    return a + b # hands back a value
 
x = real_add(2, 3) # x becomes 5
print(x * 10) # 50 — we can keep computing!
 
y = show_add(2, 3) # prints 5, but…
print(y) # None — nothing was returned!
Expected output
50
5
None
لاحظ أن y تساوي None لأن الدالة طبعت فقط ولم تُرجع شيئًا
