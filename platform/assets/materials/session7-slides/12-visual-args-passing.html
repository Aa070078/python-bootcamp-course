👁️ VISUAL — ARGUMENTS FILL PARAMETERS
Values flow in, by position
القيم تتدفق إلى المعاملات بالترتيب: الأولى إلى الأول وهكذا
position.py
def greet(name, age):
    print(f"Hi {name}, you are {age}!")
 
greet("Nour", 19)
→
ARGUMENT
"Nour" → name
ARGUMENT
19 → age
PARAMETERS
name
age
filled slots inside the function
Position matters: first argument → first parameter, second → second. 🔢
