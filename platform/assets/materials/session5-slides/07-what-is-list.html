A list is an ordered collection of items
📦 One variable, many values
Holds any type: numbers, strings, even other lists.
Keeps the order you put items in.
🔢 Written with [ ]
Items inside square brackets,
separated by commas.
first_lists.py 
scores = [85, 92, 78]
names = ["Ahmed", "Omar", "Ali"]
mixed = [1, "hello", 3.14, True]
