Each item has an index — exactly like strings!
indexing.py 
fruits = ["apple", "banana", "cherry"]

# Positive indexes
print(fruits[0])  # "apple"
print(fruits[2])  # "cherry"

# Negative indexes (from the end)
print(fruits[-1])  # "cherry"
print(fruits[-3])  # "apple"

Positive: left → right, from 0
-3  -2  -1
apple  banana  cherry
Negative: right → left, from -1
