enumerate.py 
menu = ["Koshari", "Ful", "Tamiya"]

# enumerate gives you BOTH index and value
for i, item in enumerate(menu):
    print(f"{i}. {item}")

# 0. Koshari
# 1. Ful
# 2. Tamiya

# Start from 1 (for a menu!)
for i, item in enumerate(menu, 1):
    print(f"{i}. {item}")  # 1. Koshari ...
enumerate(list)
Pairs each item with its index automatically.
enumerate(list, 1)
Start counting from 1 instead of 0 — perfect for menus & rankings.
