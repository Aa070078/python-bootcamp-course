LENGTH — len()
طول القائمة
len(list) returns the number of items — exactly like strings
len_demo.py 
students = ["Ahmed", "Omar", "Ali", "Sara"]
print(len(students))  # 4

# Empty list has length 0
todo = []
print(len(todo))      # 0

# Last item is at index len(list) - 1
print(students[len(students) - 1])  # "Sara"
