classroom = [
    ["Ahmed", 95],
    ["Omar",  88],
    ["Sara",  91],
]

# Outer index → inner list
print(classroom[0])      # ["Ahmed", 95]

# [row][col] → single value
print(classroom[0][0])  # "Ahmed"
print(classroom[0][1])  # 95

# Loop over all rows
for row in classroom:
    print(row[0], "scored", row[1])
list[row]
Picks one whole inner list.
list[row][col]
Dive into the inner list: first index → row, second → column.
for row in list
Loop through rows, then index each one.
