in and not in check if a value exists
searching.py 
students = ["Ahmed", "Omar", "Ali", "Sara"]

# in → True if value exists
print("Omar" in students)  # True
print("Zara" in students)  # False

# not in → opposite
print("Zara" not in students)  # True

# Real use: check before removing
if "Ali" in students:
    students.remove("Ali")
    print("Removed!")
💡 Checking with in before remove() avoids the ValueError.
