sorting.py 
scores = [88, 95, 70, 92]

# sort() — sorts IN PLACE (modifies)
scores.sort()
print(scores)  # [70, 88, 92, 95]

# reverse() — flips in place
scores.reverse()
print(scores)  # [95, 92, 88, 70]

# sorted(list) — returns a NEW list
names = ["Zara", "Ali", "Omar"]
ordered = sorted(names)
print(ordered)  # ["Ali", "Omar", "Zara"]
print(names)    # unchanged ✅
🔄 sort() vs sorted()
sort() — changes the list, returns None
sorted() — returns a new sorted list, original stays
💡 reverse=True sorts descending: scores.sort(reverse=True)
