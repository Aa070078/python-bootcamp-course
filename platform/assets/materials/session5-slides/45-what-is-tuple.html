WHAT IS A TUPLE?
ما هو الصف Tuple؟
A tuple is an ordered, immutable collection
🔒 Immutable
Once created, you CANNOT add, remove, or change items. Trying to → TypeError.
📝 Written with ( )
Parentheses instead of square brackets. Access items by index — just like lists.
tuples.py 
point = (3, 4)
colors = ("red", "green", "blue")
single = (42,)   # comma required!

print(point[0])  # 3  (same indexing)
print(len(colors))  # 3
