names = ["Ahmed", "Omar", "Ali"]
print(names[3])

# IndexError: list index out of range
# The list has indexes 0, 1, 2 only.

# Fix: check the length first
if 3 < len(names):
    print(names[3])
else:
    print("Index out of range!")
🚨 IndexError
Happens when you use an index that doesn't exist.

Last valid index is always len(list) - 1.
