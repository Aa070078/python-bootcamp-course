COMMON MISTAKES
أخطاء شائعة يجب تجنبها
MISTAKE 1
scores[3] on a 3-item list
→ IndexError. Last index is len-1. Use negative indexes for "last".
MISTAKE 2
sort() when you want the result
→ sort() returns None! Use sorted() to get a new sorted list.
MISTAKE 3
b = a thinking it copies
→ Changes through b change a too. Use b = a.copy().
MISTAKE 4
t[0] = 9 on a tuple
→ TypeError. Tuples are immutable — that's their superpower.
MISTAKE 5
remove(x) without checking in
→ ValueError if x is missing. Guard with if x in list first.
MISTAKE 6
for i in len(names)
→ TypeError: int not iterable. Use for name in names.
