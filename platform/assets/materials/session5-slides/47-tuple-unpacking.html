Extract every value into variables in one line
unpacking.py 
point = (3, 4)

# One line — two variables!
x, y = point
print(x)  # 3
print(y)  # 4

# Real-world: swapping values
a, b = 5, 10
a, b = b, a
print(a, b)  # 10 5 — no temp variable needed!

# Works on lists too
name, score = ["Ahmed", 95]

Unpacking is used everywhere — enumerate(), zip(), nested lists. You already saw it in Session 4!
