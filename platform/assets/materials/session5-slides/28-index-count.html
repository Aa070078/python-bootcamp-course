grades = [90, 85, 90, 77, 90]

# index(x) — first position of x
print(grades.index(85))  # 1
print(grades.index(90))  # 0  (first one)

# count(x) — how many times
print(grades.count(90))  # 3
print(grades.count(50))  # 0 (not there)
.index(x)
Returns the first index where x appears. Errors if x is missing.
.count(x)
Counts how many times x appears. Returns 0 if absent.
