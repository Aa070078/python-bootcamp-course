b = a does NOT copy the list!
aliasing.py 
a = [1, 2, 3]
b = a   # b points to the SAME list

b.append(4)

print(a)  # [1, 2, 3, 4] 😱
print(b)  # [1, 2, 3, 4]
🎯 Both names → ONE list
Lists are objects.
Assignment shares the object — changes through one name affect the other.
