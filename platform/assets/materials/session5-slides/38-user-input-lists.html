⭐ The "aha" moment — your first dynamic program
todo_list.py 
todo = []

while True:
    task = input("Add task ('quit' to stop): ")
    if task == "quit":
        break
    todo.append(task)
    print(f"Tasks: {todo}")

print(f"Done! You have {len(todo)} tasks.")
What's happening here?
1. List starts empty
2. while True keeps asking
3. Each answer is appended
4. The list grows with the user!
