LIST vs TUPLE
القائمة مقابل الصف
📦 LIST []
✅ Mutable — change anytime
✅ append / insert / remove / pop
✅ sort in place
✅ Great for changing data
Students, cart items, tasks
🔒 TUPLE ()
❌ Immutable — fixed forever
✅ Faster + safer
✅ Cannot be accidentally changed
✅ Great for fixed data
Coordinates, RGB, constants
Rule of thumb: if the data must never change → tuple. If it can change → list.
