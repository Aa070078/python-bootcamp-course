الدمج zip
zip() pairs items from two lists together
zip.py 
names  = ["Ahmed", "Omar", "Sara"]
scores = [95, 88, 91]

# Pair them up!
for name, score in zip(names, scores):
    print(f"{name}: {score}")

# Ahmed: 95
# Omar: 88
# Sara: 91

# zip() also returns pairs as tuples
print(list(zip(names, scores)))
# [("Ahmed", 95), ("Omar", 88), ("Sara", 91)]
🤝 Like a zipper
Takes position 0 of each list, then position 1, and so on. Perfect for connecting names with scores.
