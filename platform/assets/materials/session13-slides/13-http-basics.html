🧱 CORE CONCEPT #4
HTTP basics
HTTP = HyperText Transfer Protocol.
The language of the web — the rules both sides agree on.
A REQUEST LOOKS LIKE
GET /latest?from=USD&to=EUR HTTP/1.1
Host: api.frankfurter.app
Method · path · version + headers. That's all a request is.
A RESPONSE LOOKS LIKE
HTTP/1.1 200 OK
Content-Type: application/json

{ "base": "USD", "rates": { "EUR": 0.92 } }
Version · status code · headers · body.
Good news: you never write this raw text by hand — the requests library writes it for you. But you must understand it to read errors.
HTTP هو "لغة الويب": طريقة موحّدة يرسل بها العميل طلبه ويستقبل بها الخادم إجابته 🔤
