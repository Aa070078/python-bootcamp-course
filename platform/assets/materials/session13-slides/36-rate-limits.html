⏱️ CORE CONCEPT #18
Rate limits
APIs are shared. Too many requests too fast → server says 429 Too Many Requests. Be a polite guest. 🤝
import time
import requests

for i in range(5):
    resp = requests.get("https://api.frankfurter.app/latest")
    print(resp.status_code)
    time.sleep(1)  # 1 second pause between calls
GOOD API CITIZEN
🐢 sleep() between calls — don't hammer
📄 Read the docs for your free limit
💾 Cache answers — don't re-fetch what you have
🛑 If you see 429, stop and wait

Free tiers: typically ~10–60 requests/minute.
Real servers may also return Retry-After in headers telling you when to ask again.
