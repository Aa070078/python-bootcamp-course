🔑 CORE CONCEPT #16
API keys
Some APIs ask "who are you?" before answering. Your answer is an API key — a secret passphrase they gave you.
WHY KEYS EXIST
🎫 Identity — the server knows it's really you
📊 Usage tracking — how many calls you make
🚧 Limits — free tier caps, paid tiers unlock more

Treat it like a password: never share it, never commit it.
HOW IT'S SENT
headers = {"X-Api-Key": "YOUR_KEY"}
resp = requests.get(
    "https://api.example.com/weather?city=Cairo",
    headers=headers,
)
Usually in the headers — not in the URL. (Slide 22 🔙)
✅ Today's APIs are key-free — great for learning. Wrong/no key → 401 Unauthorized.
مفتاح الـ API هو بطاقة هويتك لدى الخدمة: لا تشاركه أبداً، وضعه في الترويسات لا في الرابط 🔑
