Dissecting a URL
https://api.open-meteo.com/v1/forecast?latitude=30.05&current_weather=true
scheme — the protocol (always https for secure APIs)
host — which server
path — the endpoint (which "dish")
query string — starts with ? and carries options
Options come in key=value pairs joined by &. That's a query parameter — our next stop. →
