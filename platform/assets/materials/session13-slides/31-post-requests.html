POST — send data
GET reads. POST creates. You send a JSON body; the server replies with what it saved.
import requests

new_post = {
    "title": "Hello API",
    "body": "My first POST",
    "userId": 1,
}

resp = requests.post(
    "https://jsonplaceholder.typicode.com/posts",
    json=new_post,
)

print(resp.status_code)  # 201 Created
print(resp.json()["id"]) # new id
WHAT CHANGED?
post( instead of get(
json=new_post sends the dict as the body

Server replies 201 Created + the saved object with a new id.

⚠️ We use a test-only API (JSONPlaceholder) — it doesn't really save, but it behaves like a real one.
