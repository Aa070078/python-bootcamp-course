⚠️ COMMON MISTAKES
Don't fall for these
❌ MISTAKES
• Forgetting to check status_code
• Printing resp.text and treating it as a dict
• Sharing API keys / committing them to Git
• No try/except around the network call
• Hand-writing URLs with messy strings instead of params
✅ THE FIX
• if resp.status_code != 200: handle it
• data = resp.json() before indexing
• Keys in headers, secrets in env vars
• try/except requests.exceptions.RequestException
• params={...} and let requests build the URL
🧠 If your program breaks, read the traceback first — 9 times out of 10 it names the exact fix.
Common error messages you'll see: KeyError (wrong key) · ConnectionError (no internet) · HTTPError 404 (raise_for_status fired).
