📦 CORE CONCEPT #10
JSON — the API format
JSON = JavaScript Object Notation. It's just text — but text shaped like Python dictionaries and lists.
Because it's plain text, ANY programming language can read it. That's why the whole web chose it. 🌍
WHAT YOU ALREADY KNOW
{"name": "Sara", "age": 19} # dict
[1, 2, 3] # list
JSON = dicts and lists written as text. That's it.
DATA TYPES
string — "Cairo"
number — 38.2
boolean — true / false
null — nothing / missing
object / array — nested data
Tiny note: JSON spells true / null, Python spells True / None. requests converts for you.
JSON صيغة نصية تشبه قواميس Python وقوائمها، ولهذا تستطيع كل اللغات قراءتها 📦
