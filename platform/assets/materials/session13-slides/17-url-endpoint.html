📍 CORE CONCEPT #6
URL & endpoint
URL = a full address. Endpoint = one specific "door" on that server that answers a particular question.
https://api.frankfurter.app/latest?from=USD
HOST / DOMAIN
Which server — like a city name.
api.frankfurter.app = the currency server.
PATH / ENDPOINT
Which resource — like a street name.
/latest = "give me today's rates".
Endpoints follow a pattern: /orders · /orders/42 · /forecast. Read the docs to learn the menu. 📖
الـ URL عنوان كامل، والـ Endpoint باب محدد على الخادم يجيب عن سؤال واحد محدد 📍
