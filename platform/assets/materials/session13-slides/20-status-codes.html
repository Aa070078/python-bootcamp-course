🚦 CORE CONCEPT #8
HTTP status codes
The server's one-line verdict. Read the hundreds digit first — it tells you the category.
2xx 🟢
Success
200 OK · 201 Created
3xx 🟡
Redirect
301 Moved — look elsewhere.
4xx 🟠
Your fault (client)
404 Not found · 401 Unauthorized
5xx 🔴
Server fault
500 Error · 503 Unavailable
Memorize the famous three: 200 all good · 404 not found · 500 server broke.
200 يعني نجاح، 404 يعني غير موجود، 500 يعني عطل الخادم — الأرقام هي "حكم" الخادم على طلبك 🚦
