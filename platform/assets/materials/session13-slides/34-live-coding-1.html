Build a weather app 🌦️
We ask Open-Meteo for Cairo's weather — no API key needed. Type along with me, one line at a time.
import requests

URL = "https://api.open-meteo.com/v1/forecast"

params = {
    "latitude": 30.05,
    "longitude": 31.24, # Cairo
    "current_weather": "true",
}

resp = requests.get(URL, params=params)
data = resp.json()
WHY THESE PIECES?
URL = the endpoint (slide 17)
params = the question (slide 28)
resp.json() = the answer as a dict (slide 29)

Stop here and run it! print(data) to see everything the server gave us.
