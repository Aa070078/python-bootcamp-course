Which method reads?
Your app needs to show a list of a user's orders.
Which HTTP method fits best?
A) POST — create a new order
POST changes data — not a read.
B) GET  ✅
Reading data = GET. Nothing changes on the server.
C) PUT — update an order
PUT edits existing data.
D) DELETE — remove an order
DELETE destroys data.
