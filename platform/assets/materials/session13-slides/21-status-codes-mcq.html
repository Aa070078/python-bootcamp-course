✅ QUICK CHECK #3
Decode the status code
You ask for a weather report for the city "Narnia".
The API replies 404. What does that tell you?
A) Success — the data is ready
Success codes start with 2.
B) The city wasn't found  ✅
404 = "resource not found" — wrong city, wrong path.
C) The server crashed
Server crashes are 5xx.
D) The request needs a password
That would be 401 or 403.
404 ليست عطلاً في الكود — إنها رسالة: "المورد المطلوب غير موجود" 🚦
