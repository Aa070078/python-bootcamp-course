📖 CORE CONCEPT #1
What is an API?
API = Application Programming Interface.
It's the agreed-upon language two programs use to talk to each other.
🐍 Program A
Your Python script.
Wants data. Doesn't know where it lives.
⇄
🖥️ Program B
A server somewhere.
Has the data. Publishes it through an API.
📦 The API
A menu of allowed questions + the format of answers.
Key insight: an API doesn't give you the server's database — it gives you a controlled door with rules. No touching the messy stuff inside.
API اختصار لـ "واجهة برمجة التطبيقات" — وهي الباب المنظَّم الذي يتحدث من خلاله برنامجان 🚪
