👀 VISUAL — A REAL RESPONSE
What the server sends back
This is a real (trimmed) response from api.open-meteo.com — the weather API we'll use for live coding.
{
  "latitude": 30.05,
  "longitude": 31.24,
  "timezone": "Africa/Cairo",
  "current_weather": {
    "temperature": 38.1,
    "windspeed": 11.2,
    "weathercode": 1,
    "is_day": 1,
  }
}
HOW TO READ IT
temperature = the number we want: 38.1°C 🔥

The outer "current_weather" holds a nested dict.

To reach it in Python:
data["current_weather"]["temperature"]

Keys are strings in quotes — always.
