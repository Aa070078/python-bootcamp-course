🤝 CORE CONCEPT #3
Client vs Server
Every API conversation has two roles. Someone asks, someone answers.
💻 CLIENT
The one who asks. A phone, a browser, your Python script.
Always initiates the conversation. Sends the request.
requests.get(...) ← your code, the client
⇄
🖥️ SERVER
The one who answers. A powerful machine that waits, 24/7, for requests.
Checks your question, grabs the data, sends a response.
→ returns data as JSON
Your laptop can be both: a client now (calling weather APIs) and a server later (in another session). One program can even be both at once.
العميل هو من يطلب، والخادم هو من يجيب — وهكذا يدور حوار كل الـ APIs 🤝
