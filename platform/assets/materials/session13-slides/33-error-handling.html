🛡️ CORE CONCEPT #17
Handle API errors
The server doesn't crash your program — it replies with an error code. YOU decide what to do with it.
import requests

def get_rate(currency):
    url = f("https://api.frankfurter.app/latest?from=USD&to={currency}")
    resp = requests.get(url)

    if resp.status_code != 200:
        print(f("Error {resp.status_code}: {resp.reason}"))
        return None
    data = resp.json()
    return data["rates"][currency]

print(get_rate("EUR"))
THE 3-STEP SHIELD
1️⃣ Check the code — is it 200?
2️⃣ Decide — print, return None, or retry
3️⃣ Protect — wrap network calls in try/except:
except requests.exceptions.RequestException

Never let a missing internet connection crash the whole app.
Pattern: check status → handle gracefully. You'll use this in the project. 🛡️
