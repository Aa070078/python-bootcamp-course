🧠 PREDICT THE OUTPUT #2
Nested keys 🔑
import requests

resp = requests.get(
    "https://api.open-meteo.com/v1/forecast",
    params={
        "latitude": 30.05,
        "longitude": 31.24,
        "current_weather": "true",
    },
)

data = resp.json()
print(data["current_weather"]["temperature"])
YOUR GUESS
What does the last print(...) output?

A) A dictionary
B) A number, e.g. 38.1
C) A KeyError crash
D) The whole JSON

Answer in the notes. 🤫
Trace the keys: "current_weather" → a dict; then "temperature" → a number.
