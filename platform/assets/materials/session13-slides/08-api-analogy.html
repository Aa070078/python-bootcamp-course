🎨 VISUAL — THE RESTAURANT
APIs are menus. 🍽️
😀 You (the client)
Sit at the table. You know what you want, but you cannot cook.
"I'd like a pizza" 🍕
→
🙋 The waiter (the API)
Knows exactly which dishes exist and carries the order back.
Menu → order → deliver 🛎️
→
👨‍🍳 Kitchen (the server)
Has the ingredients and makes the dish. You never walk in.
"Here's your pizza 🍕"
The waiter never lets you see the kitchen. You can only order what's on the menu — that's the API contract. ✨
Mapping to real life: Menu = list of endpoints · Dish = the data · Order = your request
