🚀 CORE CONCEPT #12
Your first GET
Four lines. One real API. Live currency rates. Let's go. 🐍
import requests

resp = requests.get(
    "https://api.frankfurter.app/latest?from=USD&to=EUR"
)

print(resp.status_code)  # 200
print(resp.text)      # raw JSON as text
WHAT HAPPENS
1️⃣ requests.get() builds the request
2️⃣ Sends it to frankfurter.app
3️⃣ Program waits for the answer
4️⃣ Everything lands in the resp object

status_code → 200
text → the JSON as a string
If you have internet, run it right now. If the network is off, the code is still correct — it just needs a connection.
