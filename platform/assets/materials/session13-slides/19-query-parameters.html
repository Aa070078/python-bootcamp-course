🔑 CORE CONCEPT #7
Query parameters
Options you pass to an endpoint: which city, which currency, how many results.
STRUCTURE
?key1=value1&key2=value2
Starts with ?. Pairs joined by &.
Order usually doesn't matter.
REAL EXAMPLE
/latest?from=USD&to=EUR
"Latest rates, converting from USD to EUR".
Each API defines its own parameter names — read the docs. Common ones: q, limit, page, lang.
