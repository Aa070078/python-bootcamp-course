📨 VISUAL — TWO ENVELOPES
Request vs Response
📤 REQUEST (what YOU send)
Method — what do you want to do? (GET, POST…)
URL — who do you want it from?
Headers — extra info (who you are, keys)
Body — optional data you're sending
"GET me the current temperature in Cairo"
⇄
📥 RESPONSE (what you get back)
Status code — did it work? (200, 404…)
Headers — meta info about the answer
Body — the actual data, usually JSON
"200 OK → {"temp": 38, "city": "Cairo"}"
In Python, resp.status_code and resp.text read those two parts for you.
