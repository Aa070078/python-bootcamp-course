⚙️ CORE CONCEPT #13
GET with query params
Don't hand-build URLs — let params do it cleanly (it even URL-encodes spaces for you).
import requests

params = {
    "from": "USD",
    "to": "EUR",
}

resp = requests.get(
    "https://api.frankfurter.app/latest",
    params=params,
)

print(resp.url)  # built for you
WHAT REQUESTS DOES FOR YOU
Your dict { "from": "USD", "to": "EUR" }
becomes the query string:

?from=USD&to=EUR

resp.url shows the final URL.

Clean, readable, and it handles encoding. 👌
Rule: use params= for options. Never jam them into the URL string by hand.
استخدم معامل params بدلاً من كتابة الـ URL يدوياً — المكتبة تبني العنوان الصحيح نيابة عنك ⚙️
