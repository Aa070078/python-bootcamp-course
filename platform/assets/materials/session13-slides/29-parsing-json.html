🧰 CORE CONCEPT #14
Parse the JSON response
resp.json() turns the JSON text into a real Python dict. Then it's yours to explore. 🔍
import requests

resp = requests.get(
    "https://api.frankfurter.app/latest",
    params={"from": "USD", "to": "EUR"},
)

data = resp.json()

print(type(data))         # <class 'dict'>
print(data["base"])       # USD
print(data["rates"]["EUR"]) # 0.92...
THE PIPELINE
resp.text → string of JSON
resp.json() → Python dict

Then dict access works as usual:
data["rates"]["EUR"]

Nested? Chain the keys. Missing key? KeyError — that's your cue to re-read the docs. 📖
💡 pprint(data) prints big JSON in a readable layout — great for exploring.
