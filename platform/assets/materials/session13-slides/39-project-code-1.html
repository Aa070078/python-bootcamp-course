Fetch the rates
Write this in converter.py — a function that fetches today's rates for one currency.
import requests

BASE_URL = "https://api.frankfurter.app/latest"

def get_rates(from_currency="USD"):
    resp = requests.get(
        BASE_URL,
        params={"from": from_currency},
    )
    resp.raise_for_status()
    return resp.json()["rates"]

rates = get_rates("USD")
print("1 USD =", rates["EUR"], "EUR")
NEW TOOL: raise_for_status()
resp.raise_for_status()
Shortcut from slide 33: if the status is 4xx/5xx it raises an exception; otherwise nothing.

So our function either returns rates or fails loudly — no silent garbage.
