🗂️ CORE CONCEPT #5
HTTP methods
The verb of your request. Four verbs cover almost everything: read, create, update, delete.
GET
Read data. Safe — no changes on the server. Used constantly.
get_weather()
POST
Create new data. Sends a body with the new item.
create_user()
PUT
Update existing data. Replace or edit an item.
update_profile()
DELETE
Remove data on the server. Handle with care.
delete_post()
These four are the CRUD operations — Create, Read, Update, Delete — the backbone of every data app.
لكل فعل طريقة: GET للقراءة، POST للإنشاء، PUT للتحديث، DELETE للحذف — هذه أساس أي تطبيق بيانات 🗂️
