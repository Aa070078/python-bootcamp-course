What does CREATE TABLE do?
After running cursor.execute(...), what actually happened in the database?
A) Deleted the whole database file
DROP TABLE deletes — not CREATE.
B) Created a new table structure  ✅
Defines columns and types, ready to hold rows.
C) Connected to a remote server
SQLite is a single local file — no server.
D) Printed every row to the screen
That is SELECT + fetchall().
