How do we fetch ALL rows?
After a SELECT query, which method returns every matching row as a list of tuples?
A) fetchone()
Returns only the very first row.
B) commit()
Saves changes to the file — no rows returned.
C) fetchall()  ✅
List of tuples — one tuple per row.
D) execute()
Runs the query — fetching is separate.
