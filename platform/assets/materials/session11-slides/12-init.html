SYNTAX // THE INITIALIZER
__init__: born with data 🎂
دالة __init__ تهيئ كل كائن عند ولادته — تُستدعى تلقائيًا
dog_002.py
class Dog:
    def __init__(self, name, age):
        self.name = name  # store on the object
        self.age = age
 
rex = Dog("Rex", 3)  # __init__ runs NOW
print(rex.name, rex.age)  # Rex 3
How it works ⚙️
⏱️ __init__ fires automatically the moment you create an object.
🎯 It's the initializer — the "constructor" that sets up each new object.
🗃️ self.name = name attaches the value to this specific object.
🐍 The double underscores mean "special" — we call these dunder methods.
You never call __init__ yourself — Python calls it for you.
