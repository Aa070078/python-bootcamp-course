SYNTAX // THE class KEYWORD
Your first class 🐍
أول صنف لك — ابدأ بكلمة class وباسم يبدأ بحرف كبير
dog_001.py
class Dog:
    pass        # empty body for now
 
rex = Dog()    # make an object
bella = Dog() # another object
 
print(rex)        # <__main__.Dog object at 0x...>
print(type(rex)) # <class '__main__.Dog'>
Anatomy 🔍
class — the keyword that defines a blueprint
Dog — the class name (use PascalCase)
Dog() — builds an object ("constructor")
pass — empty body, "do nothing yet"
⚡ Try it in your terminal — instant objects, zero logic.
