JUDGEMENT // TOOL CHOICE
When OOP? When not? ⚖️
استخدم الكائنات عند الحاجة، وليس في كل سطر — اختر الأداة المناسبة
USE OOP ✅
🧩 Many objects that share structure (students, accounts, monsters)
🎭 Behavior must differ per kind (inheritance + polymorphism)
🔐 Data needs guarding (encapsulation / properties)
♻️ You'll reuse the blueprint across the app
SKIP OOP ⏭️
📝 A 15-line throwaway script
🧮 Pure math / one-off calculation (no state)
🪜 Simple top-to-bottom logic
💬 A couple of functions is all you need
💡 OOP is a tool, not a rule. Good engineers pick the simplest tool that fits — and refactor when the script grows up.
