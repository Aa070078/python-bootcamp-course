Attributes: instance vs class
الخصائص: لكل كائن خصائصه الخاصة، وأخرى مشتركة بين كل الكائنات
INSTANCE ATTRIBUTE — لكل كائن نسخته
attrs_1.py
class Student:
    def __init__(self, name):
        self.name = name # instance attr
 
s1 = Student("Lina")
s2 = Student("Omar")
s1.name = "Lina K." # s1 only
print(s1.name, s2.name) # Lina K. Omar
CLASS ATTRIBUTE — مشتركة بين كل الكائنات
attrs_2.py
class Student:
    school = "Neon High" # class attr
 
    def __init__(self, name):
        self.name = name
 
s1 = Student("Lina")
s2 = Student("Omar")
print(s1.school, s2.school) # shared
⚡ You can also add an attribute anywhere: s1.city = "Cairo" works even outside the class.
