HOOK // WHY NOT JUST FUNCTIONS?
One script. Too many lists. 😵‍💫
Data and its logic live in *different* places — one typo and they drift apart silently.
grades.py — the messy way
students = ["Sara", "Omar", "Lina"]
grades = [[85, 92], [77, 81], [90, 88]]
 
def add_grade(student, grade):
    idx = students.index(student) # name → index
    grades[idx].append(grade) # update a DIFFERENT list
 
add_grade("Sara", 95)
print(grades) # [[85, 92, 95], [77, 81], [90, 88]]
What breaks? 🤔
Student name, grades, IDs, emails… every fact about Sara is in a different list.
Delete one list, sort another → data goes out of sync.
💡 OOP keeps the data AND the logic about Sara in ONE place: an object.
