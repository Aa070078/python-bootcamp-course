OVERRIDE // SAME NAME, NEW SOUND
Method overriding: child takes over 🎙️
تجاوز الدوال: الابن يكتب نسخته الخاصة من دالة الأب
override.py
class Animal:
    def speak(self):
        return "..."
 
class Dog(Animal):
    def speak(self): # override!
        return "Woof!"
 
class Cat(Animal):
    def speak(self):
        return "Meow!"
 
print(Dog("Rex").speak())  # Woof!
print(Cat("Mimi").speak()) # Meow!
Override rules 📏
🔁 Same method name, same parameters.

🚫 The child's version wins over the parent's.

🎭 The parent method still exists — you can call it with super().speak().
Same name, different behavior per child.
