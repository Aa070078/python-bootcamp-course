UPGRADE // SAME LOGIC, NEW STRUCTURE
Refactor: script → class 🛠️
إعادة الهيكلة: من قوائم متفرقة إلى صنف واحد متماسك
BEFORE — PROCEDURAL
before.py
names = ["Sara", "Omar"]
grades = [[90], [75]]
 
def average(name):
    i = names.index(name)
    return sum(grades[i]) / len(grades[i])
 
# Sara's name & grades live in 2 lists.
# Delete from one → breaks the other.
AFTER — OOP
after.py
class Student:
    def __init__(self, name):
        self.name = name
        self.grades = []
 
    def average(self):
        return sum(self.grades) / len(self.grades)
 
sara = Student("Sara")
sara.grades.append(90)
print(sara.average()) # 90.0
➡️ Same logic, safer structure. Sara's data + her behavior now live together — refactoring isn't rewriting, it's reorganizing.
