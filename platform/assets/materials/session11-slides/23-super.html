REUSE // THE PARENT HAND
super(): call the parent's code 🤝
super() تسمح لك باستدعاء دوال الأب دون إعادة كتابتها
super_demo.py
class Animal:
    def __init__(self, name):
        self.name = name
 
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name) # parent's init
        self.breed = breed
 
rex = Dog("Rex", "Husky")
print(rex.name, rex.breed) # Rex Husky
Why? 💡
❌ Without it, you'd duplicate the parent's setup.

✅ super().__init__(name) runs the parent's initializer, then Dog adds its own extras.

🧩 Works for any parent method, not just __init__.
Reuse first. Add later.
