class Account:
    def __init__(self, owner, balance):
        self.owner = owner
        self._balance = balance # "private" by convention
 
    def deposit(self, amount):
        if amount > 0:
            self._balance += amount
 
    def withdraw(self, amount):
        if 0 < amount <= self._balance:
            self._balance -= amount
 
acc = Account("Sara", 100)
acc.deposit(50)
acc.withdraw(30)
print(acc._balance) # 120 — works, but stay out
The rule 🛡️
🏦 ATM analogy — you don't reach into the vault; you use the buttons.

🔑 _balance = internal. Underscore = "please don't touch directly".

📞 Change state through methods (deposit / withdraw) that validate first.
No negative deposits. No overdrawing. The class protects itself.
