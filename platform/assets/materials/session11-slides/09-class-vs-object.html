CLASS — the cookie cutter
One blueprint, written once. It defines what every cookie looks like.
class Cookie: # the mold
🍪🍪🍪
OBJECTS — the cookies
Made many times from the same cutter. Each cookie is separate and independent.
c1 = Cookie()  c2 = Cookie()
💡 Class = recipe (defines). Object = the actual thing (exists in memory). One class → unlimited objects.
