PRINCIPLE #3 // ONE INTERFACE
Polymorphism: one call, many forms 🎭
تعدد الأشكال: نفس الاستدعاء pet.speak() يعطي صوتًا مختلفًا حسب الكائن
polymorphism.py
class Animal:
    def __init__(self, name):
        self.name = name
 
class Dog(Animal):
    def speak(self): return "Woof!"
 
class Cat(Animal):
    def speak(self): return "Meow!"
 
zoo = [Dog("Rex"), Cat("Mimi"), Dog("Max")]
 
for pet in zoo: # one loop, every pet behaves right
    print(f"{pet.name} says {pet.speak()}")
The payoff 💥
🎠 The loop doesn't know or care which animal is which.

📞 Same call: pet.speak()
🔊 Different result per object.
Rex says Woof!
Mimi says Meow!
Max says Woof!
