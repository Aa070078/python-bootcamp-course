⚠️ TRAPS // AVOID THESE
Common mistakes 🚧
أخطاء شائعة — تجنبها ووفّر وقتًا ثمينًا
1️⃣ Forgetting self
def bark(): # ❌ no self
→ TypeError: bark() takes 0 positional args but 1 was given
Fix: def bark(self): — every method takes self first.
2️⃣ Mutable default argument
def __init__(self, grades=[]): # ❌ shared list!
Fix: grades=None, then self.grades = grades or [].
3️⃣ Skipping super().__init__()
Child defines its own __init__ → parent's never runs → AttributeError: 'Dog' object has no attribute 'name'
Fix: call super().__init__(name) first.
4️⃣ Assigning to a class attribute
s1.school = "X" # ❌ makes a NEW instance attr, hides the class one
Fix: change it on the class: Student.school = "X".
