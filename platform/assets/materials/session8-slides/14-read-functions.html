📖 CONCEPT 04 — READING
Read a file, three ways
f.read()
Everything → one string.
f.readline()
Next one line (keeps the \n).
f.readlines()
All lines → list of strings.
✨ Bonus: a file object is iterable — for line in f: loops over it line by line.
ثلاث طرق لقراءة الملف: read كل المحتوى، readline سطراً واحداً، readlines قائمة الأسطر
