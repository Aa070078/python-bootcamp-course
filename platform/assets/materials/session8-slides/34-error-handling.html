⚠️ CONCEPT 12 — FILE ERRORS
When files fight back
FileNotFoundError
Reading a file that doesn't exist. Most common crash today.
PermissionError
No permission to read/write (protected folder, locked file).
IsADirectoryError
You gave a folder path where a file is expected.
JSONDecodeError
The file's JSON is broken (missing comma, bad quote).
أخطاء شائعة: ملف غير موجود، صلاحيات مرفوضة، مسار مجلد، أو JSON تالف
