✍️ CONCEPT 05 — WRITING
Write data to a file
Open with "w" and Python creates the file if needed — but beware: it erases the old content first. ⚠️
f.write(text)
Writes one string. You add "\n" yourself — Python does not add newlines for you.
f.writelines(list)
Writes a list of strings in one call. Still no automatic "\n".
# only strings can be written — numbers need str() or f-strings
