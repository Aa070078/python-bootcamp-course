🧱 CONCEPT 11 — STRUCTURED DATA
Lists of records = real data
Real apps don't store one value — they store many records. In Python that's a list of dicts, and JSON stores it perfectly. Save → load → use.
contacts.py
import json
 
contacts = [
    {"name": "Nour", "phone": "055123"},
    {"name": "Sara", "phone": "056999"},
]
 
with open("contacts.json", "w") as f:
    json.dump(contacts, f, indent=2)
 
with open("contacts.json") as f:
    data = json.load(f)
 
print(len(data), "contacts saved")
After loading, data is a normal Python list again → loop, search, filter like any list.
2 contacts saved
for c in data:
    print(c["name"], c["phone"])
