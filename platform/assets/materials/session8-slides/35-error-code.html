try:
    with open("scores.json") as f:
        data = json.load(f)
except FileNotFoundError:
    print("⚠️ File not found — starting fresh")
    data = []
except json.JSONDecodeError:
    print("❌ File is corrupted")
    data = []
PATTERN: FAIL-SAFE LOAD
This is the default-loaded-data pattern: if the save file is missing or broken, start with an empty list instead of crashing.
You'll use this pattern in the project — every save file starts as an empty list on first run.
