🎨 VISUAL — RAM VS DISK
RAM vs Disk
⚡ RAM (memory)
Super fast · volatile
Holds your variables
✗ wiped when the program closes
💾 DISK (storage)
Slower · permanent
Holds your files
✔ survives restarts, reboots, power cuts
# program runs → data in RAM   # program closes → RAM empty, DISK keeps the file
