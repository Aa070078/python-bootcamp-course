Build: the Diary app 📓
A diary that never forgets. Type lines, they're appended to diary.txt — open it tomorrow, it's all still there.
1. 📂 open "a" append
2. ⌨️ input() a line
3. ✍️ write it + "\n"
4. 🔁 loop until "quit"
diary.py
with open("diary.txt", "a") as f:
    while True:
        line = input("> ")
        if line == "quit":
            break
        f.write(line + "\n")
 
print("Saved to diary.txt ✅")
 
# read it back
with open("diary.txt") as f:
    print(f.read())
