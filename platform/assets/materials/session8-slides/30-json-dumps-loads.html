🔄 CONCEPT 10 — SERIALIZATION
dumps / loads — string edition
dumps = dump → string. loads = load → string. They convert between Python objects and JSON text — perfect for sending data over the network.
json_strings.py
import json
 
data = {"name": "Nour", "age": 18}
text = json.dumps(data)  # dict → JSON string
print(type(text), text)
 
back = json.loads(text)  # JSON string → dict
print(back["name"])
🖥️ Output:
<class 'str'> {"name": "Nour", "age": 18}
Nour
dumps يحوّل القاموس إلى نص JSON، وloads يعيد تحويل النص إلى قاموس
