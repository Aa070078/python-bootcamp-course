🚪 CONCEPT 03 — open()
open() — the door to a file
Every file has a door. open() opens it and hands you a file object you can read from or write to. Default mode is "r" (read).
open_demo.py
# three steps to use a file
f = open("notes.txt", "r")  # 1. open the door
text = f.read()           # 2. use it
f.close()                 # 3. close the door
🚪→📄
Forgetting to close = leaving the door open. We fix this later with with.
🔑 open(path, mode) → returns a file object. You pick the mode — that's the next slide.
