Build: the Expense Tracker 💸
Track daily spending. Loads the previous expenses from JSON, appends new ones, saves everything back — then shows the total. Real app, real data.
expenses.py
import json
 
expenses = []
try:
    with open("expenses.json") as f:
        expenses = json.load(f)
except FileNotFoundError:
    expenses = []
 
while True:
    item = input("Item (or 'done'): ")
    if item == "done":
        break
    cost = float(input("Cost: "))
    expenses.append({"item": item, "cost": cost})
 
with open("expenses.json", "w") as f:
    json.dump(expenses, f, indent=2)
 
total = sum(e["cost"] for e in expenses)
print(f"💸 Total: {total}")
print("Saved to expenses.json ✅")
The pattern to internalize:
1️⃣ load (fail-safe)
2️⃣ work in memory
3️⃣ dump back
