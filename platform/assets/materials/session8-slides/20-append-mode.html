➕ CONCEPT 06 — APPEND
Append — add without deleting
Open with "a" → the file pointer starts at the end. Old content stays, new lines pile up behind it. The safe mode.
📜 Perfect for
📝 diaries & notes history
🧾 log files (app activity)
🗒️ todo lists & chat histories
🧪 Both rules
✔ creates the file if it doesn't exist
✔ never deletes existing content
✖ can't change what's already written
⚡ Memory hook: read · wipe-or-write · add — "RWA"
