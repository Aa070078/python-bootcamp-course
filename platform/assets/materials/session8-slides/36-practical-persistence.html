🎮 CONCEPT 13 — PRACTICAL PERSISTENCE
Game saves & settings
Everything you learned has one real use: remember state between runs. Here's a mini game save with high scores.
highscore.py
import json
 
def save_score(name, score):
    with open("scores.json", "w") as f:
        json.dump({"name": name, "score": score}, f)
 
def load_score():
    try:
        with open("scores.json") as f:
            return json.load(f)
    except FileNotFoundError:
        return {"name": "—", "score": 0}
 
save_score("Nour", 150)
print(load_score())
{'name': 'Nour', 'score': 150}
Run the game tomorrow → the score is still 150. That's persistence.
