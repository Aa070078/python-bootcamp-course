The memory layer
notes.py
import json
 
FILE = "notes.json"
 
def load_notes():
    try:
        with open(FILE) as f:
            return json.load(f)
    except FileNotFoundError:
        return []
 
def save_notes(notes):
    with open(FILE, "w") as f:
        json.dump(notes, f, indent=2)
Two small functions = the app's memory.
✓ load: fresh [] if missing
✓ save: pretty JSON
Every other feature calls these two. Nothing else touches the disk.
