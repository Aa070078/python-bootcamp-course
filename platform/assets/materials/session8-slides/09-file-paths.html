🗂️ CONCEPT 02 — FILE PATHS
File paths — the address of a file
A path tells Python where a file lives. Like a house address, it names the folders you must walk through to reach the file.
ABSOLUTE — full address
C:\Users\Nour\notes.txt
Works from anywhere on the computer.
RELATIVE — from here
notes.txt  or  data/users.csv
Relative to the folder where Python is running.
💡 Windows uses \ — Python accepts / everywhere. . = current folder, .. = parent folder.
