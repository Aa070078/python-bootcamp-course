🧑‍💻 CODE — CSV WITHOUT LIBRARIES
CSV with plain Python
csv_demo.py
# write a CSV
with open("scores.csv", "w") as f:
    f.write("name,score\n")
    f.write("Nour,95\n")
    f.write("Sara,88\n")
 
# read it back, split on commas
with open("scores.csv") as f:
    for line in f:
        name, score = line.strip().split(",")
        print(name, "→", score)
🖥️ OUTPUT
name → score
Nour → 95
Sara → 88
💡 strip() removes the \n, then split(",") splits the row into its cells.
