📦 CONCEPT 09 — JSON
JSON — the language of APIs
JavaScript Object Notation — a text format for structured data that literally every language can read.
🌍 WHY APIS USE IT
🔤 language-independent
👀 readable by humans
🧩 nests lists & objects freely
📲 sent by every web API you know
🐍 PYTHON ↔ JSON
dict  ↔  { } object
list   ↔  [ ] array
str/num ↔ string/number
True ↔ true  None ↔ null
🔑 When a website's API returns data → it returns JSON. And Python has a battery included: import json
JSON صيغة نصية عالمية تتبادلها كل لغات البرمجة، وهي اللغة التي تستخدمها واجهات API
