# User enters a number, program prints its multiplication table
num = int(input("Enter a number: "))

print(f"\n=== Multiplication Table for {num} ===")
for i in range(1, 11):
    print(f"{num} x {i:2d} = {num * i}")
Concepts used:
input, int(), for loop, range(), f-string formatting
Extension:
Ask user for start/end range (e.g. table 1-20)
