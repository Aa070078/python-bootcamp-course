Grade Analyzer
Given a list of student scores:

1. Find the class average
2. Count how many passed (>= 60)
3. Find the highest and lowest
4. Print a pass/fail report
Hint: Use a loop + variables for tracking
solution.py 
scores = [85, 42, 91, 38, 76, 55, 88, 92]
total = 0
passed = 0
highest = scores[0]
lowest = scores[0]

for s in scores:
    total += s
    if s >= 60: passed += 1
    if s > highest: highest = s
    if s < lowest: lowest = s

avg = total / len(scores)
print(f"Average: {avg}")
print(f"Passed: {passed}/{len(scores)}")
print(f"Highest: {highest}, Lowest: {lowest}")
