🏷️ Sum of Even Numbers
Write a program that:
1. Takes numbers from 1 to 100
2. Adds up all even numbers
3. Prints the total sum
Expected output: 2550
2+4+6+8+...+98+100 = 2550
💡 Hint: Use range(2, 101, 2) or check n % 2 == 0
solution.py 
# Solution 1 — using step
total = 0
for num in range(2, 101, 2):
    total += num
print(f"Sum of evens: {total}")

# Solution 2 — using if
total = 0
for num in range(1, 101):
    if num % 2 == 0:
        total += num
