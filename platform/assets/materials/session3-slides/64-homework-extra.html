University Eligibility Checker
Write a program that:
- Asks for a student's name
- Asks for their GPA (0.0 - 4.0)
- Asks for their age
- Checks eligibility based on:
  - GPA >= 2.5 AND age <= 30
  - Prints "Eligible" or "Not Eligible"
- Loop: ask if the user wants to check another student
Uses: while, if/elif/else, input, break
Secure Login System
Build a login system:
- Store correct username and password
- Allow 3 attempts
- On correct login, show a welcome menu
- On 3 failed attempts, lock the account
- Menu options: View Profile, Change Password, Logout
- Password change must match confirmation
Uses: while, for, if, break, continue, nested loops
