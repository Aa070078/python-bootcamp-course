WHILE LOOP // REAL SCENARIO — PASSWORD ATTEMPTS
سيناريو حقيقي — محاولات كلمة المرور
password-attempts.py 
password = "python123"
attempts = 0
max_attempts = 3

while attempts < max_attempts:
    guess = input("Enter password: ")
    attempts += 1

    if guess == password:
        print("Access granted!")
        break
    else:
        remaining = max_attempts - attempts
        print(f"Wrong! {remaining} left")

if attempts == max_attempts:
    print("Account locked!")
▶ Output 
Enter password: hello
Wrong! 2 left
Enter password: test
Wrong! 1 left
Enter password: python123
Access granted!
🔑 Key Concept: The while loop checks a LIMIT — not just a simple True/False.
