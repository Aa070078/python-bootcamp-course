Diamond Pattern
Print a diamond pattern of stars for n=5:

Use nested loops and string multiplication.
challenge.py 
# Diamond pattern for n=5
n = 5

# Upper half
for i in range(1, n + 1):
    spaces = " " * (n - i)
    stars = "* " * i
    print(spaces + stars)

# Lower half
for i in range(n - 1, 0, -1):
    spaces = " " * (n - i)
    stars = "* " * i
    print(spaces + stars)
