الحلقة الشرطية — قائمة الصراف الآلي
atm-menu.py 
balance = 1000
running = True

while running:
    print("\n=== ATM MENU ===")
    print("1. Check Balance")
    print("2. Deposit")
    print("3. Withdraw")
    print("4. Exit")

    choice = input("Choose: ")

    if choice == "1":
        print(f"Balance: ${balance}")
    elif choice == "2":
        amount = int(input("Amount: "))
        balance += amount
    elif choice == "3":
        amount = int(input("Amount: "))
        balance -= amount
    elif choice == "4":
        running = False
        print("Goodbye!")
💡 while running: Keeps loop alive until user exits
🔑 Key pattern: while True + break / flag variable
