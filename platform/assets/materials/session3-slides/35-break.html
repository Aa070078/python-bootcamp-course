break-example.py 
# Search — stop when found
students = ["Ali", "Sara", "Omar", "Lina"]
target = "Omar"

for name in students:
    if name == target:
        print(f"Found {name}!")
        break
    print(f"Checking {name}...")
▶ Output 
Checking Ali...
Checking Sara...
Found Omar!
  stopped here
🛑 break exits the ENTIRE loop. Code after the loop continues normally.
