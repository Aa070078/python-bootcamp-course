comprehension-practice.py 
# 1. Squares of even numbers only
even_squares = [x**2 for x in range(20) if x % 2 == 0]
print(even_squares)

# 2. Extract names longer than 4 chars
names = ["Ali", "Sara", "Omar", "Mohammed", "Lina"]
long_names = [n for n in names if len(n) > 4]
print(long_names)

# 3. Convert scores to grades
scores = [85, 42, 91, 38, 76]
grades = ["Pass" if s >= 60 else "Fail" for s in scores]
print(grades)

# 4. Nested comprehension — flatten
matrix = [[1,2,3], [4,5,6], [7,8,9]]
flat = [n for row in matrix for n in row]
print(flat)  # [1,2,3,4,5,6,7,8,9]
💡 Pro tip: If a comprehension gets too long, use a regular for loop — readability matters!
