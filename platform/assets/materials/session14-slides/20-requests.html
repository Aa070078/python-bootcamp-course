CORE CONCEPT // FETCHING PAGES 📡
The requests library
مكتبة requests: نرسل طلب HTTP إلى الموقع ونستلم الاستجابة التي تحتوي على نص الصفحة
1️⃣ REQUEST
Your script asks the server: "send me this page, please". Exactly what your browser does.
2️⃣ RESPONSE
Server replies with a status code + the page text. A Response object holds both.
3️⃣ STATUS CODES
200 OK • 404 missing • 403 forbidden • 5xx server problem.
💾 Install once: pip install requests — then import it in every project.
