Meet BeautifulSoup
BeautifulSoup يحوّل نص HTML إلى شجرة عناصر سهلة التنقل والبحث
🥣 From soup text to soup tree
📄 resp.text ──► 🧠 BeautifulSoup(...) ──► 🌳 soup
In goes a plain string of HTML. Out comes a tree object with tags, text and attributes. Then you can search, filter and navigate it — like a Python list of elements.
🧰 What it gives you
soup.title → first tag
tag.text → inner text
tag["href"] → attribute
find() / find_all() → search
select() → CSS selectors
