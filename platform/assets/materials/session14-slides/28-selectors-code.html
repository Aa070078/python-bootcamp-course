CODE // SELECTING WITH CLASS & ID 🎯
select() vs select_one()
select تعيد قائمة، وselect_one تعيد أول عنصر فقط
selectors.py
from bs4 import BeautifulSoup
html = """<a class="tag" href="/tag/books/">books</a>
<p id="main">Hello world</p>"""
soup = BeautifulSoup(html, "html.parser")
print(soup.select_one("p#main").text) # Hello world
print(soup.select_one("a.tag")["href"]) # /tag/books/
print(len(soup.select("a.tag"))) # 1
PATTERN
tag.class → an <a> with class tag

tag#id → a <p> with id main

["href"] → read an attribute
