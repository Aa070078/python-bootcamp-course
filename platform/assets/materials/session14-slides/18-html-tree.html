Every page is a tree
بنية الصفحة: عناصر داخل عناصر — شجرة متفرعة تبدأ من جذر واحد
<html>
  <head> … </head>
  <body>
    <h1>Title</h1>
    <div class="quote">
      <span class="text">“…“</span>
      <small class="author">Name</small>
    </div>
  </body>
</html>
html
├─ head
└─ body
   ├─ h1 Title
   └─ div.quote
      ├─ span.text “…”
      └─ small.author Name
🧠 Why it matters
The scraper climbs this tree: from div.quote it descends to span.text and small.author. Parent → children = relationships you can walk in code.
