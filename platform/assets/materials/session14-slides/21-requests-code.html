CODE // FETCHING A REAL PAGE 📡
Fetch + inspect the response
نرسل الطلب، نتحقق من الحالة، ونطبع أول جزء من الصفحة
fetch.py
import requests
url = "https://quotes.toscrape.com/"
resp = requests.get(url, timeout=10)
resp.raise_for_status() # raise if 4xx/5xx
print(resp.status_code) # 200
print(resp.headers["Content-Type"])
print(resp.text[:120]) # first characters
GOOD HABITS
✅ timeout=10 → don't wait forever
✅ raise_for_status() → catch errors early
✅ resp.text → the HTML we'll parse
عادات جيدة: مهلة زمنية، وفحص الحالة، ثم قراءة النص
