Extract the first — and all — quotes
نستخرج أول عنصر ثم جميع العناصر المطابقة، ونقارن بين find وfind_all
find_demo.py
from bs4 import BeautifulSoup
html = "<div class='quote'><span class='text'>Hi</span></div><div class='quote'><span class='text'>Bye</span></div>"
soup = BeautifulSoup(html, "html.parser")
first = soup.find("div") # first div only
print(first.get_text()) # Hi
all_quotes = soup.find_all("div", class_="quote")
print(len(all_quotes)) # 2
WATCH OUT
find returns a Tag — print it with .get_text() or it shows raw HTML. If you get None, your filter didn't match.
