CORE CONCEPT // BEING BLOCKED 🚧
Your scraper is "blocked". Now what?
متى يُحظر الكاشطة؟ اقرأ العلامات وتصرف بأدب — لا تتجاوز القيود
🚨 Warning signs
• 403 / 429 status codes
• You get a CAPTCHA page instead of data
• "Access denied" / human-check pages
• Data comes back empty after it worked before
✅ The right response
✔ Slow down — sleep longer
✔ Stop — respect the block
✔ Check robots.txt & ToS
✔ Use an official API if one exists

Never try to bypass CAPTCHAs or anti-bot systems.
