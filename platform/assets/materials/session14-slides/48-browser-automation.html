🚧 The problem
Some pages load data after the page via JavaScript ("load more", infinite scroll, login walls). resp.text is empty of data.
🎮 The tools
Selenium or Playwright launch a real browser that runs the JavaScript, then you read the rendered page.
👆 Superpowers
Open pages, click buttons, fill forms, wait for elements — automation, not just reading.
⚠️ Remember the rules: automation never bypasses logins, CAPTCHAs or anti-bot systems — it just runs the same browser you use.
