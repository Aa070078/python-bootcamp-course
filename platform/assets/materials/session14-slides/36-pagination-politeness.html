CORE CONCEPT // PAGINATION + POLITENESS 🔁
More than one page? Loop it — slowly
عند تعدد الصفحات: حلقة مع مهلة انتظار بين كل طلب — كاشطة مهذبة
paginate.py
import time, requests
for page in range(1, 4):
    url = f("https://quotes.toscrape.com/page/{page}/")
    resp = requests.get(url, timeout=10)
    resp.raise_for_status()
    print(f("page {page} -> {resp.status_code}"))
    time.sleep(2) # polite pause between requests
THE POLITE PAUSE
time.sleep(2) → wait 2s between requests. A human can't click 1000 pages in a minute — don't pretend to.

Check robots.txt for the site's Crawl-delay.
