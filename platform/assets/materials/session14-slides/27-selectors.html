CORE CONCEPT // CSS SELECTORS 🎯
CSS selectors
محددات CSS: لغة اختصار للعثور على العناصر حسب النوع والخاصية والموقع
tag
All elements of a tag: "h1", "li", "a"
.class
Shared label: ".quote", ".price" — the classic pattern
#id
Unique element: "#main", "#header"
div .item
Descendant: .item inside a div
💬 In code: soup.select(".quote") → same as find_all(class_="quote"), but shorter & more powerful
المحدد .quote يعني: كل العناصر التي تحمل هذا الفئة — نفس معنى find_all(class_="quote")
