What is Web Scraping?
ما هو كشط الويب؟ هو استخراج البيانات من صفحات الويب آليًا باستخدام برنامج بدلًا من البشر
👀
You (the human)
Open the browser, eyeball the page, copy-paste what you need. Slow. Boring. 10 tabs/min.
🤖
Your script
Fetches the page as text, finds the interesting parts, stores them. Fast. Repeatable. 1000 pages/min.
📦 Scraping = copy the data • API = server gives you the data (both read the web; scraping reads the page itself)
