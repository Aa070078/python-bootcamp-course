CORE CONCEPT // SEARCHING THE TREE 🔍
find() and find_all()
find تعيد أول عنصر مطابق، وfind_all تعيد قائمة بكل العناصر المطابقة
soup.find("h1")
Returns the first match, or None if nothing matches. → 1 element (or nothing).
FIRST MATCH
soup.find_all("li")
Returns a list of every match. Loop over it: for item in soup.find_all("li").
ALL MATCHES
find_all("span", class_="price")
Filter by tag AND attribute. Note: class_ with underscore (class is a keyword).
FILTERED
🕵️ find() = "give me one" • find_all() = "give me the list" • results are Tag objects, use .text
