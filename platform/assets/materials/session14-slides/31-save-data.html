CODE // SAVING RESULTS 💾
JSON, CSV — then reuse it anywhere
نحفظ القائمة في ملفات JSON وCSV لاستخدامها في التحليل لاحقًا
save_books.py
import csv, json
rows = [{"title": "Dune", "author": "Frank Herbert"},
        {"title": "1984", "author": "George Orwell"}]
with open("books.json", "w", encoding="utf-8") as f:
    json.dump(rows, f, indent=2, ensure_ascii=False)
with open("books.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "author"])
    writer.writeheader()
    writer.writerows(rows)
WHEN WHICH?
🗂️ JSON → nested data, re-import with json.load
📊 CSV → spreadsheets / Excel / pandas
🗄️ SQLite → big data + queries (session 12!)
CSV للجداول، JSON للهياكل المتداخلة، SQLite للبيانات الكبيرة
