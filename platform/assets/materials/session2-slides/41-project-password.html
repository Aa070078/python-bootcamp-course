// REQUIREMENTS
01
Ask the user for a password.
02
Check if length >= 8 characters.
03
Check if it contains at least one number.
04
Check if it contains at least one letter.
05
Print "Strong", "Medium", or "Weak".
Hint:
.isalnum() checks for letters/numbers. .isdigit() checks for digits.
password.py
pw = input("Password: ")
has_letter = any(c.isalpha() for c in pw)
has_number = any(c.isdigit() for c in pw)
if len(pw) >= 8 and has_letter and has_number:
print("Strong 💪")
elif len(pw) >= 6:
print("Medium ⚡")
else:
print("Weak 🐛")
