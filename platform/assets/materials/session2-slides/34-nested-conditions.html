# Real example: theme park entry
age = 16
has_ticket = True
if age >= 18:
    print("You can enter alone")
else:
    # nested: check ticket
    if has_ticket:
        print("Enter with guardian")
    else:
        print("Buy a ticket first")
→ Enter with guardian
// THE FLOW
1. Is age >= 18? → No (16)
  → Go to else
2. Inside else: Is has_ticket True? → Yes
  → Print "Enter with guardian"
3. Done — skips inner else
// ⚠️ WARNING
Nested conditions work, but too many levels
make code hard to read. If you have 3+ levels,
consider using and/or to combine conditions.
Better alternative:
if age >= 18 or has_ticket:
