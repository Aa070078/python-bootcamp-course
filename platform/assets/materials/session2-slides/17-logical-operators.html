Logical Operators.
Combine truths. Answer big questions with tiny words.
العمليات المنطقية — بتجمع أسئلة كتير في سؤال واحد
and
True only if BOTH are True
صح لو الاتنين صح — أي واحد غلط، النتيجة غلط
True and True → True
True and False → False
False and True → False
False and False → False
Real: "must be adult AND have ticket"
age >= 18 and has_ticket
or
True if AT LEAST ONE is True
صح لو واحد على الأقل صح
True or True → True
True or False → True
False or True → True
False or False → False
Real: "weekend OR holiday → sleep in"
is_weekend or is_holiday
not
Flip the value — True ↔ False
اقلب القيمة — صح يبقى غلط، والعكس
not True → False
not False → True
Only 2 rows — it's a flipper.
Real: "not logged in → show login"
not is_logged_in
