MISTAKE #1
= vs ==
if x = 5: ← WRONG (assignment)
if x == 5: ← RIGHT (comparison)
MISTAKE #2
Missing colon
if x == 5 ← WRONG
if x == 5: ← RIGHT
MISTAKE #3
Indentation error
if True:
print("hi") ← WRONG
print("hi") ← RIGHT
MISTAKE #4
Wrong operator in condition
if x = 5 and y = 10: ← WRONG
if x == 5 and y == 10: ← RIGHT
Remember: = assigns, == compares
MISTAKE #5
is vs ==
== checks VALUE: 5 == 5.0 → True
is checks IDENTITY: 5 is 5.0 → False
Use == for values, is for None/True/False
