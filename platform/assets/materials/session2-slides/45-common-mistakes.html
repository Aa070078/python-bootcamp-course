DEBUGGING // COMMON BEGINNER MISTAKES
Common Mistakes.
أخطاء شائعة — لو انت عملتها قبل كده، مش لوحدك!
// MISTAKE 01
Missing colon
if x > 5
if x > 5:
Every if/elif/else line needs :
// MISTAKE 02
Wrong indentation
if True:
print("hi")
if True:
  print("hi")
Indented code = inside the if block
// MISTAKE 03
= vs == in conditions
if x = 5:
if x == 5:
= assigns. == compares.
// MISTAKE 04
Condition always True
if True: # always runs!
if age >= 18: # real check
Use a real comparison, not just True/False
// MISTAKE 05
elif after else
if/else/elif
if/elif/else
else always comes LAST
// MISTAKE 06
Multiple blocks run
if/if/if (all run)
if/elif/else (one runs)
Use elif when only ONE should run
