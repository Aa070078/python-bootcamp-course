DEEP DIVE // == vs is — THE MOST CONFUSED PAIR
== vs is — pick the right one.
الفرق بين == و is — أشهر خطأ عند المبتدئين
==
Value equality — "do they LOOK the same?"
5 == 5 # True
"Ali" == "Ali" # True
[1,2] == [1,2] # True (same contents)
3 == 3.0 # True (same value)
is
Same object — "is this the SAME thing?"
a = [1,2]
b = [1,2]
a == b # True (values match)
a is b # False (different objects!)
a is a # True (same object)
