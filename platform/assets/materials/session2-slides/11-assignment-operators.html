Assignment Operators.
Store values in variables — with math shortcuts.
التخصيص — بتخزّن قيم، ومختصرات ذكية لتعديلها
=
Assign — put a value in a variable
x = 10  → x now holds 10
+=
Add and store — same as x = x + 5
x += 5  → 10 becomes 15
−=
Subtract and store
x -= 3  → 15 becomes 12
*=
x *= 2 → doubles x
/=
x /= 2 → halves x
// MENTAL MODEL
Every shortcut is just: "take the current value, do math, save it back."
x += 5 # same as
x = x + 5
score += 1 # "add 1 point"
lives -= 1 # "lose 1 life"
gold *= 2 # "double coins"
Why bother?
Shorter · clearer · standard everywhere in real code.
