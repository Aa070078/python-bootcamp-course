// REQUIREMENTS
01
Ask for weight (kg) and height (m).
02
Calculate: BMI = weight / height²
03
Classify the result using if/elif/else:
Under 18.5 → "Underweight"
18.5 – 24.9 → "Normal"
25 – 29.9 → "Overweight"
30+ → "Obese"
04
Print both the BMI value and the category.
bmi.py
weight = float(input("Weight (kg): "))
height = float(input("Height (m): "))
bmi = weight / height ** 2
print(f"BMI: {bmi:.1f}")
if bmi < 18.5:
print("Underweight")
elif bmi < 25:
print("Normal")
elif bmi < 30:
print("Overweight")
else:
print("Obese")
