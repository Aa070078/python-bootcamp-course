CHALLENGE 01
Triangle Classifier
Ask for 3 sides. Classify as: Equilateral (all equal), Isosceles (two equal), or Scalene (none equal). Also check if it's a valid triangle (sum of any two sides > third).

Shipping Cost Calculator
Ask for weight (kg) and distance (km). Price: base $5 + $0.50/kg + $0.10/km. If weight > 20 → extra $10. If distance > 100 → add 10% surcharge. Print itemized receipt.
