Membership Operators.
Ask: "is this inside that?"
العضوية — بتسأل: الحاجة دي موجودة جوه دي ولا لأ؟
in
True if the value is inside the collection
صح لو موجود جواه
# check inside a list
3 in [1, 2, 3] # True
7 in [1, 2, 3] # False
# check inside a string
"a" in "Cairo" # True
"z" in "Cairo" # False
"Cai" in "Cairo" # True (substring)
not in
True if the value is NOT inside
صح لو مش موجود
# practical use — banned words
banned = ["spam", "virus"]
word = "hello"
word not in banned # True → allow
# email domain check
"@" not in "invalid" # True → bad email
