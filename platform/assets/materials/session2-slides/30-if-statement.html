The if statement.
جملة if — أول أمر شرطي في حياتك
if_example.py
# Basic if statement
age = 20
if age >= 18:
print("You can vote!")
# Python checks: age >= 18 → True → runs indented code
# --- another example ---
temperature = 35
if temperature > 30:
print("It's hot outside!")
print("Drink water.")
print("This runs no matter what.")
// 3 RULES
1. Colon after condition if age >= 18:   2. Indentation = block (4 spaces)   3. Only indented code runs inside the if
Indentation is NOT optional in Python.
It's how Python knows what's inside the if.
