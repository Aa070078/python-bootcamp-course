CONDITIONS // THE IF STATEMENT
// FAMILY 01 OF 03
if
Run code only when a condition is true.
لو — شغّل الكود بس لما الشرط يبقى صحيح
// SYNTAX
syntax.py
if condition:
    do_something()
# condition is True → runs
# condition is False → skips
// EXAMPLE
example.py
age = 20
if age >= 18:
    print("You can vote!")
→ You can vote!
// 3 RULES TO REMEMBER
1. Always ends with : (colon)     2. Indented code runs when True     3. No indentation = runs always
