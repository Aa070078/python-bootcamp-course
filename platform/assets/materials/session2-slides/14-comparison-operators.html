Comparison Operators.
Ask questions. Get back True or False.
المقارنات — بتسأل Python سؤال وترد بـ True أو False
==
Equal to
5 == 5 → True
!=
Not equal
5 != 3 → True
>
Greater than
10 > 3 → True
<
Less than
3 < 10 → True
>=
Greater or equal
5 >= 5 → True
<=
Less or equal
3 <= 5 → True
// TRAP #1 — REMEMBER THIS FOREVER
= assigns a value into a variable. == compares two values. They are DIFFERENT operators.
