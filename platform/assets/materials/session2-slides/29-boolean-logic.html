CONDITIONS // BOOLEAN LOGIC
// TRUE OR FALSE — NOTHING ELSE
Everything is True or False.
كل حاجة في الشروط إما True أو False — مافيش حاجة في النص
// IN PYTHON, THESE ARE TRUTHY
True              → obviously True
1, 42, -7        → any non-zero number
"hello", "ali"   → any non-empty string
[1, 2, 3]        → any non-empty list
Rule: non-empty = True
// IN PYTHON, THESE ARE FALSY
False            → obviously False
0, 0.0          → zero is False
""             → empty string is False
None           → nothing = False
[]             → empty list is False
Rule: empty / zero / None = False
💡 if only cares about True/False. If you write if "ali": — it runs because "ali" is truthy (non-empty string).
