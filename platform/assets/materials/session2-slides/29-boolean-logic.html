CONDITIONS // BOOLEAN LOGIC
// FOUNDATION
Everything is True or False.
كل حاجة في بايثون True أو False
// TRUE — YES / ON / 1
10 > 5 → True
10 IS greater than 5
5 == 5 → True
5 IS equal to 5
"hello" → True
Non-empty string = truthy
1 → True
Non-zero number = truthy
// FALSE — NO / OFF / 0
10 < 5 → False
10 is NOT less than 5
3 != 3 → False
3 IS equal to 3, so "not equal" is False
"" → False
Empty string = falsy
0 → False
Zero = falsy
In Python, True and False are CAPITALIZED — not true/false like other languages.
