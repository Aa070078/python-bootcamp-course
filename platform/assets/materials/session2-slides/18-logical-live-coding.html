# ===== SCENARIO 1 · AGE CHECK =====
age = 20
has_id = True
print(age >= 18 and has_id) # True
# ===== SCENARIO 2 · LOGIN =====
username = "ali"
password = "1234"
ok = username == "ali" and password == "1234"
print(ok) # True
# ===== SCENARIO 3 · PERMISSIONS =====
is_admin = False
is_owner = True
can_edit = is_admin or is_owner
print(can_edit) # True
# flip with not
is_logged_in = False
print(not is_logged_in) # True → show login
# combine everything
print(age >= 18 and (is_admin or is_owner)) # True
// PATTERNS
Age check
age >= 18 and has_id
Login
user == correct and pw == correct
Permission
is_admin or is_owner
Watch out — order of operations
not runs first, then and, then or. Use ( ) when unsure.
