CONDITIONS // IF / ELIF / ELSE
// MULTIPLE CHOICES
More than two options? Use elif.
أكتر من اختيارين؟ استخدم elif
if_elif_else.py
score = 85
if score >= 90:
print("Grade: A")
elif score >= 80:
print("Grade: B")
elif score >= 70:
print("Grade: C")
elif score >= 60:
print("Grade: D")
else:
print("Grade: F")
# score = 85 → 85 >= 90? No → 85 >= 80? Yes → print "B"
# STOP — Python doesn't check the rest
