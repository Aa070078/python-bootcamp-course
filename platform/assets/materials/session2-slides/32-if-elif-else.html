CONDITIONS // IF · ELIF · ELSE
// FAMILY 03 OF 03
if / elif / else
More than two options? Add elif in the middle.
لو / لو كذا / وإلا — كل الأפשרيات
grade_system.py
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
print(grade) # → B
// HOW IT FLOWS
1. Check if score >= 90 → False
2. Check elif score >= 80 → True ✓
→ grade = "B" → DONE!
Stops checking after the first True.
skips remaining elif + else.
// KEY RULE
Only ONE block runs.
Python checks from top to bottom.
Stops at the first True.
elif = "else if" — combines two steps.
