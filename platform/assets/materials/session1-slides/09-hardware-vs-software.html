CONCEPT // HARDWARE VS SOFTWARE
Hardware vs Software
الجهاز مقابل البرنامج
🖥️
// HARDWARE
Stuff you can touch
الحاجة اللي تقدر تلمسها بإيدك
→ Screen · Keyboard · Mouse
→ CPU chip · RAM sticks
→ Hard drive · SSD
→ Battery · Speakers · Camera
Rule of thumb:
If it hurts when you drop it → hardware.
💾
// SOFTWARE
Stuff that runs on it
اللي بيشتغل جوه الجهاز — أفكار وأوامر
→ Windows · iOS · Android
→ Chrome · Safari · Firefox
→ WhatsApp · Instagram · Python
→ Fortnite · FIFA · Roblox
Rule of thumb:
If you can download or delete it → software.
