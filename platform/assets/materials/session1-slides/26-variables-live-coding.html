LIVE CODING // VARIABLES
Live coding — variables in action.
هنكتب كود بيستخدم متغيرات — كل واحد على جهازه
variables_demo.py
# store values in boxes
name = "Yousef"
age = 17
city = "Cairo"
# use them
print(name)
print("Age:", age)
print(name, "lives in", city)
# change the value inside
age = 18 # happy birthday!
print("New age:", age)
# math with variables
next_year = age + 1
print("Next year I'll be:", next_year)
output
$ python variables_demo.py
Yousef
Age: 17
Yousef lives in Cairo
New age: 18
Next year I'll be: 19
