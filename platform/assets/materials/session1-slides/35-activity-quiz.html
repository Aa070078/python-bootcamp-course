// ACTIVITY 01 · 3 MIN
"Guess the type"
Instructor shows a value on screen. Class shouts the type — int, float, str, or bool. Fastest correct answer wins a point.

// ACTIVITY 02 · 5 MIN
"Spot the bug" — pair up
Show 4 broken code snippets on screen. Pairs discuss what's wrong. First pair to raise a hand explains the bug to the class.
Missing quotes · wrong case · = vs == · adding str + int

// ACTIVITY 03 · 4 MIN
"What would you automate?"
Each student names one boring daily task they'd want Python to do for them. Instructor writes them on the board. Reference back these ideas across the whole bootcamp.
