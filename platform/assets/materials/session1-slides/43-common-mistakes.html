DEBUGGING // COMMON BEGINNER MISTAKES
The 6 mistakes every beginner makes.
6 أخطاء كل مبتدئ بيقع فيها — لو عرفتها، هتوفر ساعات
01
Forgetting quotes
print(Hello)
print("Hello")
Error: NameError — Python thinks Hello is a variable.
02
Mixing strings and numbers
age = input(); print(age + 1)
age = int(input())
Error: TypeError — can't add str + int.
03
Wrong case (Print vs print)
Print("Hi") · PRINT("Hi")
print("Hi")
Python is CASE-SENSITIVE. Name ≠ name.
04
= vs ==
if age = 18:
if age == 18:
= assigns · == compares. Different jobs.
05
Invalid variable names
2name = "Ali" · my name = "Ali"
name_2 = "Ali" · my_name = "Ali"
No starting digits · no spaces · use _
06
Missing parentheses
print "Hi" · print("Hi"
print("Hi")
Every open ( needs a close ). Every open " needs a close.
// THE #1 RULE
Read the error message. Python literally tells you what's wrong — and often what line.
