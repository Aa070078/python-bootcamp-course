LIVE CODING // BOOLEANS (bool)
The yes-or-no type.
في الحياة، كل قرار في الآخر إجابته "أيوة" أو "لأ" — Python بيحكيها بـ True و False
booleans.py
# booleans — only 2 possible values
is_student = True
is_teacher = False
# capital T and F! true/false won't work
print(is_student) # True
# comparisons return booleans
print(10 > 5) # True
print(3 == 4) # False
print(3 != 4) # True (not equal)
print("Ali" == "ali") # False (case matters!)
# store the result of a comparison
age = 17
is_adult = age >= 18
print(is_adult) # False
// COMPARISON OPERATORS
== equal to
!= not equal
> greater than
< less than
>= greater or equal
<= less or equal
The biggest beginner trap:
= assigns a value
== compares equality
