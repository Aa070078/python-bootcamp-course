RULES // NAMING VARIABLES
Naming your variables.
قواعد تسمية المتغيرات — Python صارم في ده
// ✅ ALLOWED
name — simple letters
age — short and clear
first_name — underscore between words
score_2 — numbers OK (not at start)
is_student — great for True/False
total_price — describes what it holds
Convention: snake_case — all lowercase, words joined with _
// ❌ NOT ALLOWED
2name — can't start with a number
first name — no spaces (use _)
first-name — dashes look like minus
my@name — no special chars (@ # ! $)
print — Python keyword (reserved)
class — reserved word
Case-sensitive: Name ≠ name ≠ NAME
