Working with numbers.
Python يبقى آلة حاسبة قوية جداً
numbers.py
# integers (int)
age = 17
year = 2026
temp = -5
# floats — decimals
price = 15.99
pi = 3.14
grade = 92.5
# the 5 basic math operators
print(10 + 3) # 13 addition
print(10 - 3) # 7 subtraction
print(10 * 3) # 30 multiplication
print(10 / 3) # 3.333... (always float!)
print(10 ** 2) # 100 power (10²)
print(10 % 3) # 1 remainder (modulo)
# mixing int + float = float
total = 10 + 2.5 # 12.5
// KEY TAKEAWAYS
int
Whole numbers — no decimal point.
float
Has a decimal point — even 5.0 is a float.
/
Division always gives a float, even if the answer is whole.
%
Modulo — remainder. Useful for "is it even?" checks.
**
Power — 2 ** 10 is 2 to the 10th = 1024.
