CONCEPT // COMPILER vs INTERPRETER
Two ways to translate.
فيه طريقتين علشان يترجم الكود — واحدة دفعة واحدة وواحدة سطر بسطر
📚
// COMPILER
Translate the whole book first
ترجم الكتاب كله الأول، بعدين اقراه
1. Write all your code
2. Run compiler → makes .exe file
3. .exe runs directly on CPU
4. Errors caught before running
Languages:
C · C++ · Rust · Go · Java
✓ Fast to run · ✗ Slow to write & test
🎙️
// INTERPRETER
Translate line-by-line, live
ترجم كل سطر لحظة تنفيذه — زي المترجم الفوري
1. Write one or many lines
2. Interpreter reads line 1 → run it
3. Then line 2 → run it
4. Errors caught while running
Languages:
🐍 Python · JavaScript · Ruby · PHP
✓ Fast to write & test · ✗ Slower to run
