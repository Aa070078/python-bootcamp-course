TOOL // type() — ASK PYTHON
type()
Ask Python: "what kind of value is this?"
اسأل Python — إيه نوع البيانات دي
types.py
print(type(42)) # <class 'int'>
print(type(3.14)) # <class 'float'>
print(type("Yousef")) # <class 'str'>
print(type(True)) # <class 'bool'>
# with variables too
age = 17
print(type(age)) # <class 'int'>
# surprise! quotes turn numbers into strings
x = "17"
print(type(x)) # <class 'str'> ⚠️
// WHY YOU'LL USE THIS
Debugging
"Why doesn't my math work?" → check the type first.
Understanding input()
Everything from input() is str — even if user types 17.
Remember:
Quotes make everything a string. Even "17" is text, not a number.
