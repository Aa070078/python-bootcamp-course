// 4 COMMANDS YOU NEED TODAY
pwd
"Where am I?" — prints your current folder.
فين أنا حالياً — في أنهي فولدر
ls (Mac/Linux) · dir (Windows)
"What's here?" — lists files in current folder.
أعرض كل الملفات اللي في الفولدر
cd folder-name
"Go into this folder." cd .. to go back.
ادخل جوه فولدر معين
python filename.py
"Run this Python file!" — the magic command.
شغّل ملف Python — الأمر السحري
