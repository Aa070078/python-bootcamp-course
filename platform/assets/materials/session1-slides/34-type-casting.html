TOOL // TYPE CASTING — CONVERT TYPES
Type casting.
Turn one type into another. "17" becomes 17.
حوّل من نوع لنوع — من نص لرقم أو العكس
// CAST TO INT
int()
int("17") → 17
int(3.9) → 3 # cuts decimal!
int("hi") → ValueError
// CAST TO FLOAT
float()
float("3.14") → 3.14
float(10) → 10.0
float("5") → 5.0
// CAST TO STRING
str()
str(17) → "17"
str(3.14) → "3.14"
str(True) → "True"
// THE INPUT + INT PATTERN — YOU'LL USE THIS ALL THE TIME
age = int(input("How old are you? "))
print(f"Next year you'll be {age + 1}")
