Working with text.
أي كلام لازم يبقى بين علامتي اقتباس
strings.py
# both quote styles work — pick one and stay consistent
name = "Yousef"
city = 'Cairo'
# joining strings — the + operator concatenates
full = name + " from " + city
print(full) # Yousef from Cairo
# repeat with *
print("ha" * 5) # hahahahaha
# f-strings — mix text + variables
age = 17
print(f"My name is {name} and I am {age}")
# useful string things
print(len(name)) # 6 (letters count)
print(name.upper()) # YOUSEF
print(name.lower()) # yousef
// WATCH OUT
Numbers in quotes are text!
"5" + "3" → "53"
5 + 3 → 8
Match your quotes!
✓ "hello" 'hi'
✗ "hello' 'hi"
f-string tip
The f before the quote lets you drop variables in { }. Learn it — you'll use it forever.
