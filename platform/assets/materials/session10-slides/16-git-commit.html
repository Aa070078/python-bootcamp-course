COMMAND #4 // git commit
⚡ COMMAND #4 — THE HEART OF GIT
git commit
Save a permanent snapshot with a message explaining what you did.
bash
$ git commit -m "Add rock-paper-scissors game"
[main a1b2c3d] Add rock-paper-scissors game
 2 files changed, 45 insertions(+)
# -m = the message ("why/what")
# a1b2c3d = short commit hash (unique id)
$ git status
On branch main
nothing to commit, working tree clean 🎉
📸
What just happened
• The whole staging area became one snapshot
• Every commit gets a unique hash
• The commit is saved forever in history
• Working tree is now clean ✓
git commit -m "message" working tree clean = nothing pending
git commit يحفظ لحظة كاملة في تاريخ مشروعك مع رسالة تصفها.
