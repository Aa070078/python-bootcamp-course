COMMANDS #8 & #9 // PUSH & PULL
⚡ COMMANDS #8 & #9
push & pull
Sync your local repo with your GitHub remote.
bash
# after adding a remote named "origin"
$ git push -u origin main # send commits UP ⬆️
Enumerating objects: 5, done.
To https://github.com/you/my_game.git
* [new branch] main -> main
$ git pull origin main # fetch DOWN ⬇️
Already up to date.
# after -u, later runs are just: git push / git pull
🔁
When to use each
push → after you commit, upload it
pull → before you start work, get latest
Always pull before you push! 🤝
push = upload commits pull = download commits pull before push
الدفع يرسل التزاماتك إلى GitHub، والسحب ينزّل التغييرات الجديدة إلى جهازك.
