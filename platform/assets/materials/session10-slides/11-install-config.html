⚙️ SETUP
Install Git & introduce yourself
1️⃣ Download from git-scm.com → install with defaults.
2️⃣ Check it works — run git --version.
3️⃣ One-time identity setup (see terminal →).
bash — one-time setup
$ git --version
git version 2.45.1.windows.1
$ git config --global user.name "Your Name"
$ git config --global user.email "you@example.com"
$ git config --global init.defaultBranch main
$ git config --list
user.name=Your Name
user.email=you@example.com
--global = once per computer use the email you'll register on GitHub
ثبّت Git مرة واحدة، عرّف نفسك باسمك وبريدك، ثم انطلق في كل مشاريعك.
