CONCEPT // THE REPOSITORY
🧠 CONCEPT
A repository = your project + .git
📁 my_game/
    ├── .git/ ← the magic folder
    ├── app.py
    ├── score.py
    └── README.md
🔐
What is .git?
A hidden folder created by git init. It stores the whole history, hashes and versions. You never edit it — Git does.
Delete it → history gone. It IS the repository.
repo can live locally and a copy on GitHub
المستودع: مجلد مشروعك + مجلد .git السري الذي يحفظ كل التاريخ.
