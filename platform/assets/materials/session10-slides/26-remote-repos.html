PART 3 // GITHUB & REMOTES
☁️ CONCEPT
Remote repositories
💻 YOUR COMPUTER — LOCAL
Full history lives here. You work, commit, and only sync when you want.
my_game/  ← your repo
push ▲
⇄
pull ▼
🐙 GITHUB — REMOTE
A copy hosted online. It's the "official" shared version and your backup.
origin  ← default remote name
Key ideas 🗝️
• A repo can live in both places at once.
• push = send local commits up · pull = fetch remote changes down.
