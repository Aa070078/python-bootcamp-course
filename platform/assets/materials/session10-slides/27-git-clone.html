⚡ COMMAND #7
git clone
Copy a remote repository to your machine — history included.
bash
$ git clone https://github.com/you/awesome_game.git
Cloning into 'awesome_game'...
remote: Enumerating objects: 42, done.
Receiving objects: 100% (42/42), done.
$ cd awesome_game
$ git log --oneline # full history is here!
g7h8i9j Fix score bug
a1b2c3d Initial commit
📥
Why clone?
• Get a full copy of anyone's public repo
• The whole history comes with it
• Start contributing to real projects
• Works with any repo URL — even ones you don't own
git clone URL = copy to your disk
