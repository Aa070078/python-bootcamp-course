Step 2: commit the code, then push it to GitHub
bash — commit + push
1 $ git add . # stage all the code files
2 $ git commit -m "Add final game code"
  [main 7f3e9a1] Add final game code
3 $ git remote add origin https://github.com/you/my_project.git
4 $ git push -u origin main
  * [new branch] main -> main
# later: edit app.py → add → commit → push again
🔄
Upgrade & re-push
1️⃣ Change one feature in app.py
2️⃣ git add .
3️⃣ git commit -m "Add level select"
4️⃣ git push # -u remembered origin
Edit → commit → push. That's the pro rhythm.
add . → commit -m → push repeat after every feature
