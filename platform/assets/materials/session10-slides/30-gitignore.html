🔑 PRO TIP
.gitignore
A list of files Git should never track. Keeps your repo clean & safe.
.gitignore
# Python cache — no one needs these
__pycache__/
*.pyc
# virtual environments
venv/
# secrets — NEVER commit these!
.env
# OS junk
.DS_Store
🕵️
Why it matters
• Repo stays small & clean
• No leaked passwords or API keys
• No 5000-file cache garbage

Create it, then git add .gitignore + commit it.
__pycache__/ venv/ .env ← secrets
