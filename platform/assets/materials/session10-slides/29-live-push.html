LIVE CODING // PUSH TO GITHUB
🖥️ LIVE CODING — PUSH TIME
Get your repo onto GitHub
STEP 1  github.com → New repository → name it → Create (don't add files yet)
STEP 2  Copy the git remote add origin ... line GitHub shows you
bash — step 3
$ git remote add origin https://github.com/you/my_game.git
$ git remote -v # verify the link
origin https://github.com/you/my_game.git (fetch)
origin https://github.com/you/my_game.git (push)
$ git push -u origin main
* [new branch] main -> main
🔮
Predict!
After git push, what do you see on GitHub?
→ Your files, the commit history, and the green main branch. 🎉
Auth pop-up? Sign in once with your GitHub account — the computer remembers you.
