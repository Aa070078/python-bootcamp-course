# remote has commits you don't have locally → pull first!

fatal: not a git repository
# you're in the wrong folder → cd into the project (or git init)
remote: Repository not found.
# URL is wrong or private → check https://github.com/you/repo

# commit opened the editor by mistake → ESC :q! Enter

Debug recipe
1️⃣ Read the LAST line of the error
2️⃣ Run git status — where are you?
3️⃣ Google the exact error message
4️⃣ Stay calm — the repo is safe 🔒
Almost every error is fixable in seconds.
