Pull requests & open source
A Pull Request (PR) says: "I changed something on my copy — please review it and merge it into yours." That's how millions of people improve public projects together.
1  🍴 Fork the repo # copy to your GitHub
2  📥 git clone your fork # to your laptop
3  🌿 branch + make your change
4  💾 commit with a clear message
5  🚀 push to YOUR fork
6  🔀 Open a Pull Request # propose the change
💡 Contribute for real: look for "good first issue" labels. Real experience, real PRs.
