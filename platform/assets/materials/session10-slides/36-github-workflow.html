💼 WORKFLOW
The basic GitHub workflow
1  ✍️ Write / edit code # in your editor
2  📋 git add . # stage your changes
3  💾 git commit -m "msg" # save a snapshot
4  🚀 git push # upload to GitHub
5  🔄 git pull # grab teammates' changes
6  ♻️ repeat 1 → 5 forever
Remember the golden order ⭐
edit → add → commit → push — and pull before you start.
سير عمل GitHub: اكتب، التزم، ادفع، واسحب التغييرات الجديدة — وكرر.
