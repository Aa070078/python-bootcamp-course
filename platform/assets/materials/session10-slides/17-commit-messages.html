PRO TIP // COMMIT MESSAGES
💎 PRO TIP
Write messages your future self can read
😵 Bad messages
git commit -m "stuff"
git commit -m "asdf"
git commit -m "fix"
In 3 months, "fix" means nothing. 😩
✨ Good messages
git commit -m "Fix score bug in level 3"
git commit -m "Add boss level with health bar"
git commit -m "Refactor menu into its own module"
Rule: short sentence, present tense, says WHAT/WHY.
commit small & often one logical change per commit
اكتب رسائل التزام واضحة يقرأها زملاؤك و"أنت المستقبلي" بسهولة.
