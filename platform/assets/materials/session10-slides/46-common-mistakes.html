⚠️ EXTRA
Common Git mistakes (& fixes)
❌ Committing secrets (.env, passwords)
✅ fix: add to .gitignore, remove from repo
❌ Messages like "asdf"
✅ fix: describe what + why
❌ Committing __pycache__/
✅ fix: .gitignore + git rm -r --cached
❌ Forgetting git add → commit with nothing staged
✅ fix: add first, then commit
❌ git commit without -m → Vim screen 😱
✅ fix: ESC → :q! → Enter, retry with -m
❌ Editing files directly on GitHub
✅ fix: edit locally, commit, push
❌ git init inside a sub-folder
✅ fix: init once at the PROJECT root
❌ Deleting the .git folder "to fix it"
✅ fix: never. you lose all history.
mistakes are normal Git forgives — almost everything
