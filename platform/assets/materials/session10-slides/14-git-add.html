COMMAND #3 // git add
⚡ COMMAND #3
git add
Pick the files you want in the next snapshot → they go to the staging area.
bash
$ git add app.py
# or: stage everything in this folder
$ git add .
$ git status
Changes to be committed:
  new file:   app.py
  new file:   score.py
# now they are STAGED — ready for commit
🎯
Ways to add
git add app.py
git add score.py utils.py
git add *.py # all python files
git add . # everything
`git add .` is the bootcamp favourite. 🔥
git add . = stage all git add file.py = stage one
git add تضع ملفاتك في قائمة الانتظار قبل الحفظ النهائي.
