Git vs GitHub
GIT 🔧
The tool on your computer
• Tracks versions locally
• Runs from the terminal
• Works with NO internet
• Free & open source
You type the commands today. 💻
GITHUB 🐙
The website in the cloud
• Hosts remote copies of repos
• Backup + share your code
• Collaborate with others
• Your public coding profile
GitHub runs Git in the cloud. ☁️
Git = engine GitHub = garage together = superpower
