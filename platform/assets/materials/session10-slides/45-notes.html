📚 CHEAT SHEET
Git & GitHub — one page
bash — everyday commands
Setup  git config --global user.name "Name"
          git config --global user.email "you@ex.com"
Start   git init -b main   # make repo
Check   git status       # what changed?
Stage   git add .       # select files
Save   git commit -m "message"   # snapshot
History git log --oneline     # view history
Compare git diff        # see changes
Branch  git switch -c name   # new branch
          git switch main        # back
          git merge name        # combine
Remote  git remote add origin <url>
          git push -u origin main  # upload
          git pull origin main     # download
          git clone <url>     # copy repo
Golden habits ⭐
• pull before you start work
• commit small, commit often
• write messages for your future self
• never commit secrets (.env)
• .gitignore first, always
Print this. Pin it. Live it. 🖨️
