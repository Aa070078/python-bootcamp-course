⚡ COMMAND #1
git init
Turn any folder into a repository — Git starts watching it.
How it works
• Creates the hidden .git/ folder
• Names your default branch (we use -b main)
• The repo is born — still empty, no commits yet
• Run it ONCE per project, inside the project folder
bash
# inside your project folder
$ cd my_game
$ git init -b main
Initialized empty Git repository in
C:/Users/you/my_game/.git/
$ git status
On branch main
No commits yet
$ git init -b main one-time per project
git init تحوّل أي مجلد إلى مستودع يتابعه Git.
