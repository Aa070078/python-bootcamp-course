💻 TERMINAL
Branch commands in 60 seconds
bash
$ git branch # list branches, * = current
* main
$ git switch -c feature-boss # create + switch
Switched to a new branch 'feature-boss'
$ git branch
  main
* feature-boss
$ git switch main # back to main
$ git merge feature-boss # bring branch in
🗂️
Remember
• switch = move between branches
• -c = "create" then switch
• merge runs FROM main, TOWARD the branch
• older tutorials use checkout — same idea
switch -c name = create+move switch main = move back merge = combine
أوامر الفروع: branch للعرض، switch للتنقل، merge للدمج.
