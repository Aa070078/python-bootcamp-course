CORE // 12 — WRITE YOUR OWN
🛠️ Create your own module
Two files. One imports the other. You are now a library author.
helpers.py — our module
def add(a, b):
    return a + b
 
def greet(name):
    return f("Hello {name}!")
main.py — the user
import helpers
 
print(helpers.add(2, 3))     # 5
print(helpers.greet("Ali"))  # Hello Ali!
The rules of the game 📐
1️⃣ Both files live in the same folder (Python looks there first).
2️⃣ import helpers uses the filename without .py.
3️⃣ Functions are reached via helpers.add — the dot again.
4️⃣ Naming: lowercase, no spaces — my_helpers.py not My Helpers.py.
ضع الملفين في نفس المجلد، واستورد باسم الملف دون .py، وسمِّ ملفاتك بأحرف صغيرة.
