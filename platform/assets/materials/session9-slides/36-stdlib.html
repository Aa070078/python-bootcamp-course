🧩 The Standard Library
"Batteries included" — Python ships with hundreds of free modules. You never start from zero.
math — square roots, π random — dice, shuffle datetime — dates & clocks json — save & load data os — files & folders statistics — mean, median
stdlib_tour.py
import statistics
import random
 
print(statistics.mean([90, 85, 98]))  # 91.0
print(random.choice(["cat", "dog"])) # random pick
print(sum(range(1, 101)))        # 5050 (built-in!)
Developer superpower 💪
▶ Before coding, ask: "Is there a module for this?"

▶ Searching docs beats reinventing. random → don't write your own RNG!

▶ Built-ins like sum(), len(), range() are always there.
