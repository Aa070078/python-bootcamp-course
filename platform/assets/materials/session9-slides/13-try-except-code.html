CODE // 03 — THE SHIELD IN ACTION
🛡️ Shield the risky parts
read_score.py
try:
    f = open("score.txt")
    score = int(f.read())
    print("Best score:", score)
except FileNotFoundError:
    print("No score yet — start fresh!")
except ValueError:
    print("score.txt is corrupt (not a number).")
Two risks, two shields
1️⃣ File is missing → FileNotFoundError caught → friendly message.

2️⃣ File has garbage text → ValueError caught → friendly message.

🔁 Multiple except blocks = one shield per danger type. Python checks them top→bottom and runs the first match.
💡 This is the pattern for every project today: anticipate each failure, give each its own except.
لكل خطر درع خاص: ملف مفقود يعالج بـ FileNotFoundError، ومحتوى تالف يعالج بـ ValueError.
