CODE // 08 — A REAL BUSINESS RULE
🏷️ Define, raise, catch
bank.py
class InsufficientFundsError(Exception):
    pass
 
def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(
            f"Need {amount}, have {balance}")
    return balance - amount
 
try:
    withdraw(50, 200)
except InsufficientFundsError as e:
    print("Blocked:", e)
Read it aloud 🗣️
1️⃣ Define: the class creates a brand-new exception type.

2️⃣ Raise: withdraw(50, 200) trips the rule → f"..." builds a rich message.

3️⃣ Catch: only THIS rule is handled; other errors still crash loudly.
Output: Blocked: Need 200, have 50
المثال كامل: عرّف الاستثناء، ثم ارفعه عند مخالفة القاعدة، ثم التقطه في المتصل واطبع الرسالة.
