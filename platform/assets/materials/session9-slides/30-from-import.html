CORE // 11 — FROM...IMPORT
🎁 from ... import ...
Grab only what you need — no dot required afterwards.
from_import.py
from math import sqrt, pi
from datetime import datetime
 
print(sqrt(25))         # 5.0 (no math. needed)
print(pi)                 # 3.14159...
print(datetime.now())    # current date + time
import vs from
import math → math.sqrt() — everything, dotted.

from math import sqrt → sqrt() — one name, no dot.

⚠️ Name clash risk: a name you import directly can overwrite your own (or vice versa). Use from for a few specific things.
from import يستورد أسماء محددة فقط وتستخدمها دون نقطة، لكن احذر من تعارض الأسماء.
