CODE // 13 — THE GUARD IN ACTION
🚧 Before & after the guard
helpers.py — NO guard (bad)
def add(a, b):
    return a + b
 
print("helpers loaded!")  # 🚨 runs on import too!
print(add(1, 1))        # 🚨 test code leaks!
helpers.py — WITH guard (pro)
def add(a, b):
    return a + b
 
if __name__ == "__main__":
    print("helpers loaded!")
    print(add(1, 1))
🖥️ python helpers.py → prints in BOTH versions.
🔌 import helpers → left leaks "helpers loaded!"; right stays silent. ✅
