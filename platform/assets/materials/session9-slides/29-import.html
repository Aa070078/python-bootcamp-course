CORE // 10 — THE IMPORT STATEMENT
🔌 import
Plug the whole module in. Access its contents with module.name.
import_demo.py
import math
import random
 
print(math.sqrt(144))      # 12.0
print(math.pi)              # 3.141592653589793
print(random.randint(1, 6))  # random 1..6
How to read it 🧭
import math → "load the module, keep it as the name math".

Then use math.sqrt, math.pi — dot notation = "inside math, get sqrt".
✅ Never name clashes: math.sqrt can't collide with your own sqrt.
import يحمّل الوحدة كاملة وتصل إليها بالنقطة: math.sqrt تعني "داخل math استخرج sqrt".
