import json

def get_int(prompt, low, high):
    while True:
        try:
            value = int(input(prompt))
        except ValueError:
            print("Not a number. Try again.")
            continue
        if low <= value <= high:
            return value
        print(f("Enter a number between {low} and {high}."))
Read it line by line 🔍
▶ while True — never give up on asking.

▶ try int(input()) — risky conversion.

▶ except ValueError → message → continue re-asks.

▶ if low ≤ value ≤ high — range check.

▶ return value — first valid number wins.
