CORE // 01 — KNOW YOUR ENEMY
🐞 Three kinds of errors
Before you fix bugs, you must classify them. Different errors → different fixes.
SYNTAX
Grammar 💢
You broke the language rules. Python refuses to even run it.
SyntaxError: expected ':'
→ Fix spelling & structure. Found at startup.
RUNTIME
Crash 💥
Valid code that blows up mid-run: bad data, missing file, bad input.
FileNotFoundError
→ Handle it: today's main course (try/except).
LOGICAL
Wrong answer 🧩
Runs perfectly, no error message — but the result is wrong.
total = price * 0.05 # 5% not 15%!
→ The sneakiest. No crash to catch — test your logic.
ثلاثة أنواع من الأخطاء: أخطاء الصياغة تمنع التشغيل، وأخطاء التنفيذ تسبب الانهيار أثناء العمل، والأخطاء المنطقية تعطي نتائج خاطئة دون أي رسالة.
