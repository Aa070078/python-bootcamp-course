CORE // 07 — DEFENSE IN DEPTH
🎯 Input validation — the golden habit
Never trust the user. Validate every value before you use it.
🚧
Two layers
1️⃣ Catch it — try/except around risky conversions.

2️⃣ Check it — if conditions on ranges & values (0 ≤ age ≤ 120).
The recipe 🍳
1️⃣ Wrap conversion in try/except → handle "not a number".
2️⃣ Apply if checks → handle "out of range".
3️⃣ Loop until valid — keep asking instead of quitting.
4️⃣ Return the clean value.
while True:
  try: age = int(input("Age: "))
  except ValueError: continue # 🔁 retry
  if 0 <= age <= 120: break
  print("0-120 please.")
The program asks again instead of crashing — this is professional UX.
لا تثق بالمستخدم أبدًا: تحقق من المدخل، وإذا كان خاطئًا أعد السؤال بدلًا من الانهيار.
