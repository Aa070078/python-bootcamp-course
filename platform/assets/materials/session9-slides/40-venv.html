🛡️ Virtual environments (venv)
Each project gets its own private package world — no more "works on my machine".
The problem 🤯
▶ Project A needs requests 1.x.

▶ Project B needs requests 2.x.

▶ Installed globally, they fight each other 😵

✅ A venv gives each project its own folder of packages.
The mental model 🧠
▶ A venv = a private sandbox folder (e.g. .venv).

▶ When activated, pip installs go inside it — global stays clean.

▶ Same Python, same code, different package sets — no conflicts.

🔁 Deactivate to return to the global world.
