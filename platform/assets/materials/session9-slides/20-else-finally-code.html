read_data.py
try:
    f = open("data.txt")
    text = f.read()
except FileNotFoundError:
    print("No data.txt yet.")
else:
    print("Read successful!", len(text), "chars")
finally:
    print("Cleanup done.")
Two runs, same finally
✅ File exists: "Read successful!" then "Cleanup done."

❌ File missing: "No data.txt yet." then "Cleanup done."

🔁 finally printed in both cases — that's its promise.
💡 else only on success; except only on failure; finally every single time.
finally مضمون في الحالتين: سواء نجحت القراءة أو فشلت، يظهر "Cleanup done" دائمًا.
