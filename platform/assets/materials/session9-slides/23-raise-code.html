CODE // 06 — QUALITY CONTROL
🚦 raise + catch = full control
The same function can raise at the gate and be caught by the caller.
withdraw.py
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("Insufficient funds")
    return balance - amount
 
try:
    new_balance = withdraw(100, 250)
except ValueError as err:
    print("Rejected:", err)
else:
    print("New balance:", new_balance)
What happens? 🎬
withdraw(100, 250) → raises ValueError because 250 > 100.

The caller's except ValueError as err catches it and prints the message.

🧠 as err = "give me the exception object" — so we can read err (the message we raised).
Output: Rejected: Insufficient funds
