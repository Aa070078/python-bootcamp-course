🎯 MCQ — Name that exception
Which exception does this line raise?
mystery.py
user = input("How many siblings? ")
count = int(user)  # user typed "three" 😅
int() got the string "three". Which exception is raised?
A  TypeError B  ValueError C  KeyError D  SyntaxError
✔ Answer: B — the value is wrong (it IS a string, just not convertible). ValueError.
النوع صحيح (نص) لكن القيمة غير قابلة للتحويل، لذلك الاستثناء هو ValueError وليس TypeError.
