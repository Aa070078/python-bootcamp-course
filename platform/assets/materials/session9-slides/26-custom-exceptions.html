CORE // 08 — YOUR OWN EXCEPTIONS
🏷️ Custom exceptions
Built-in types don't fit everything. Make your own — with a name that speaks your app's language.
Why custom? 🤷
▶ "ValueError" says nothing about YOUR business.
▶ "InsufficientFundsError" says everything. 💰

🧠 Rule: one class per business rule. Catch them separately, handle them differently.
class InsufficientFundsError(Exception):
    pass
That's it. Your exception now exists and behaves like any other.
The pattern 🧬
1️⃣ Define: class MyError(Exception): pass
2️⃣ Raise: raise MyError("explain it")
3️⃣ Catch: except MyError: — handle just this rule

🔗 Inherit from Exception so it behaves like a true exception (caught by except Exception too).
اصنع استثناءً خاصًا بتطبيقك: class جديد يرث من Exception، ثم raise له، ثم except له وحده.
