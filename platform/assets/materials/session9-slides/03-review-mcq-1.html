📖 Review MCQ #1 — Opening files
review.py
with open("notes.txt") as f:
    content = f.read()
What is the default mode of open() here?
A  'w' — write B  'r' — read C  'a' — append D  'x' — exclusive create
✔ Answer: B — reading is the default mode of open().
وضع القراءة 'r' هو الوضع الافتراضي لدالة open في بايثون.
