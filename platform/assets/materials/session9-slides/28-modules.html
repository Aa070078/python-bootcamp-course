CORE // 09 — ORGANIZE YOUR CODE
📦 What is a module?
A module is simply a .py file. Its functions, variables and classes become reusable building blocks.
🗄️
One file = one module
Write math_utils.py once. Import it in 10 other programs. Write once, reuse forever.
You already used modules! json, math, random — all .py files somewhere on disk.
Why split code into modules? 🧠
✅ Readability — 3000-line files scare humans.
✅ Reuse — import your helpers anywhere.
✅ Teamwork — each dev owns a file.
✅ Testing — debug one small file at a time.

💡 Rule of thumb: if a file is doing 3 different jobs, split it.
الوحدة النمطية هي ملف .py بسيط؛ تُكتب مرة واحدة وتُستعمل في مشاريع كثيرة، تمامًا مثل json وrandom.
