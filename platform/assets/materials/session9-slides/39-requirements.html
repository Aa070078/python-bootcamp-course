📋 requirements.txt
A simple shopping list for your project's packages — so anyone can rebuild your setup in one command.
requirements.txt
# every line = one package
requests
colorama==0.4.6        # pinned version
rich>=13.0         # minimum version
terminal
# install everything at once
$ pip install -r requirements.txt
Successfully installed requests colorama rich
 
# generate it from current env
$ pip freeze > requirements.txt
🎁 Hand your friend this one file → they run one command → identical environment. This is how real projects ship dependencies.
