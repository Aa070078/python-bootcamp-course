CORE // 03 — THE SHIELD
🛡️ try / except
The heart of the whole session. Try something risky — if it fails, except catches it and the program survives.
How it works ⚙️
▶ Python runs the code inside try:
▶ If it throws an exception → execution jumps to except:
▶ The program keeps running — no crash 💪

🧠 No exception → the except block is skipped entirely.
shield.py
try:
    age = int(input("Your age: "))
    print("Next year:", age + 1)
except ValueError:
    print("That wasn't a number 😉")
 
print("The program survives!")
🚀 Try it: run once with 17, once with banana — both end with the last line printed.
