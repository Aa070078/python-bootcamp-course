🚀 pip — the package installer
The stdlib is great — but the real power is millions of packages from the Python community.
What is pip? 🧰
▶ pip = Python's official app store.

▶ Downloads packages from PyPI (the Python Package Index).

▶ Examples: requests (HTTP), colorama (colored terminal), pygame (games).
One command installs a package and all its dependencies automatically.
terminal
$ pip install requests
Collecting requests...
Downloading requests-2.32.3-py3-none-any.whl
Successfully installed requests-2.32.3
 
$ python -m pip --version # check pip
After install: import requests and use it like any stdlib module. 💡 pip comes bundled with Python 3.4+.
