def load_scores():
    try:
        with open("scores.json") as f:
            return json.load(f)
    except FileNotFoundError:
        return {}
    except json.JSONDecodeError:
        print("Corrupt file. Starting fresh.")
        return {}
 
def save_scores(scores):
    try:
        with open("scores.json", "w") as f:
            json.dump(scores, f)
    except OSError:
        print("Could not save scores.")
Two rescue nets 🥅
▶ load_scores(): no file → returns {}; corrupt JSON → friendly message + fresh dict. Never crashes.

▶ save_scores(): disk error → polite warning. Game continues.

▶ Both use with open() — auto-close, no finally needed here.
