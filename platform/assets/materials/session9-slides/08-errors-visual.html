VISUAL // 01 — SPOT THE DIFFERENCE
Same line, three fates 🔍
the_line.py
# 1 — SYNTAX: missing closing quote
print("hello)  # 😵
SyntaxError: unterminated string literal
 
# 2 — RUNTIME: division by zero
print(10 / 0)  # 💥
ZeroDivisionError: division by zero
 
# 3 — LOGICAL: no error, wrong result
print(5 + 3 * 2)  # prints 11 (expect 16?) 🤔
How to tell them apart
🧐 Did it crash before running? → Syntax.
💥 Crash while running? → Runtime (an exception!).
🤔 No crash but output wrong? → Logical.
🎯 Today we master #2 — runtime errors — because they are the ones you can catch and survive.
(💡 Operator order in #3: * beats +, so 5 + 6 = 11 — that's a logic/math trap, not a crash.)
