🎯 MCQ — What does this print?
quiz.py
try:
    print(int("42"))
    print("A")
except ValueError:
    print("B")
print("C")
What is the output?
A  B B  42
A
C C  42
B
C D  C
✔ Answer: B — int("42") works, so "A" prints; except is skipped; "C" runs after the block.
لا خطأ هنا، فالتحويل نجح، لذلك يُتخطى except ويستمر البرنامج بطباعة A ثم C.
