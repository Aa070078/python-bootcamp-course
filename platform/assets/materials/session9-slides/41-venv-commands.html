CODE // 17 — THE COMMANDS
🛡️ venv on Windows — the full dance
terminal (Windows)
# 1 — create the sandbox
$ py -m venv .venv
 
# 2 — activate it (Windows)
$ .venv\Scripts\activate
(.venv) C:\your-project>
 
# 3 — install into the sandbox
$ pip install requests
 
# 4 — leave the sandbox
$ deactivate
The tell-tale sign 👀
When the prompt shows (.venv) in front — you're inside the sandbox.

No (.venv)? Then pip install hits the global world.
💡 Then a requirements.txt + fresh venv = a brand-new teammate is ready in one minute.
لاحظ ظهور (.venv) أمام الموجه — علامة أنك داخل الصندوق الرملي، و deactivate تعيدك للعالم العام.
