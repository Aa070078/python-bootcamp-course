📖 Review MCQ #2 — JSON in Python
You have a Python dict and you want a JSON string to save into a file. Which call does it?
A  json.load(data) B  json.dump(data) C  json.dumps(data) D  json.loads(data)
player = {"name": "Sara", "score": 92}
text = json.dumps(player)  # -> '{"name": "Sara", "score": 92}'
💡 Memory trick: dumps = to String, dump = to File.
The s stands for string.
✔ Answer: C — json.dumps(data) returns the JSON string.
تذكّر: dumps تُحوّل إلى نص JSON، بينما dump تكتب مباشرة إلى ملف.
