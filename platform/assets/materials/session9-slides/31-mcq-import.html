🎯 MCQ — Which import lets you write randint(1, 6)?
You want to call randint(1, 6) WITHOUT the random. prefix. Which import makes that possible?
A  import random B  from random import randint C  from random import * D  both B and C
🔍 A keeps the dot (needs random.randint).
🎯 B brings randint directly into scope — no dot.
⭐ C also works but dumps every random name in — bad hygiene, avoid.
✔ Answer: D — B is clean, C works but is messy. Best practice: B.
الأفضل استيراد الاسم المحدد only؛ الاستيراد بـ * يجلب كل شيء بلا حاجة وهو عادة سيئة.
