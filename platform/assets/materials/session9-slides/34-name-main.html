CORE // 13 — THE GUARD
🚧 __name__ == "__main__"
The famous guard. It answers one question: "Am I being run, or am I being imported?"
The two lives of a .py file 🎭
▶ Run directly: python game.py → Python sets __name__ = "__main__"

▶ Imported: import game → Python sets __name__ = "game"

🧠 The guard runs test/demo code only when run directly — imports stay clean.
Why do we care? 💡
1️⃣ Without the guard, importing your module executes the test code — printing junk, asking input, maybe crashing.

2️⃣ With it, import is silent and safe.

3️⃣ Every professional Python file ends with this guard.
