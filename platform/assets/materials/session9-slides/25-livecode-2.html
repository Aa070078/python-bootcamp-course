👨‍💻 Live Coding #2 — build a bulletproof get_int()
One function. Any number of inputs. Zero crashes.
get_int.py — step by step
# STEP 1 — loop forever
def get_int(prompt):
    while True:
        # STEP 2 — try the conversion
        try:
            return int(input(prompt))
        # STEP 3 — on bad input, loop again
        except ValueError:
            print("Please enter a whole number.")
Then use it everywhere: age = get_int("Your age: ")
🗣️ Narrate as you type: "The while True keeps the question alive. return hands back the FIRST valid number. Bad input never escapes."
