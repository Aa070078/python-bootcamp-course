➕ else & finally
Two extra blocks that make try/except complete.
else — the "all good" lane
Runs only when the try block completed with no exception. Perfect for "success" logic.
try: data = json.load(f)
except: # file broken
else: print("Parsed OK!") # ✅ success path
finally — the clean-up lane
Runs ALWAYS — error or not, return or not. Use it to close files, release resources.
try:
  f = open("data.txt")
finally: f.close() # 🧹 always runs
Order matters: try → except → else → finally.
else تُنفَّذ عند النجاح فقط، بينما finally تُنفَّذ دائمًا للتنظيف: try ثم except ثم else ثم finally بالترتيب.
