🔑 CREATING SETS
Three ways to build a set
ثلاث طرق لإنشاء مجموعة — لاحظ الفرق بين الأقواس
sets.py
# 1) curly braces — the most common way
a = {1, 2, 3}
 
# 2) set() built from any list
b = set([4, 5, 6])
 
# 3) set() from a string — splits the letters!
c = set("hello")
print(c) # {'h', 'e', 'l', 'o'}
🧠 What just happened?
set("hello") took each letter once — h, e, l, l, o became {'h','e','l','o'}. The second l was dropped! 🪄
⚠️
Empty { } is NOT a set!
Bare braces make an empty dict. For an empty set write set().
