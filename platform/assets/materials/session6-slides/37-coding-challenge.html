🔡 Challenge 1 — Letter frequency
Count how many times each letter appears in the string. Build a dict where key = letter, value = count.
solution.py 
text = "hello"
counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)
Expected → {'h': 1, 'e': 1, 'l': 2, 'o': 1}
🧑‍🤝‍🧑 Challenge 2 — Dedupe names
A class list has duplicate names. Keep only the unique names with a set — and count how many were removed.
solution.py 
names = ["Sara", "Omar", "Sara", "Lina", "Omar"]
unique = set(names)
print(len(names), "->", len(unique), "unique")
print(sorted(unique))
Expected → 5 -> 3 unique
['Lina', 'Omar', 'Sara']
💡 Hint — Challenge 1: counts.get(ch, 0) returns the current count, or 0 if the letter is new. That's the whole trick.
