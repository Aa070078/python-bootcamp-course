🧩 COMBINING EVERYTHING
Lists × Sets × Dicts
Three tools, one program — they fit together beautifully.

combine.py
# 1. List of dicts — every item is one record
students = [
    {"name": "Ahmad", "grade": 90},
    {"name": "Layla", "grade": 85},
]
print(students[1]["name"]) # Layla
 
# 2. Dict of lists — group many values under one key
team = {"attackers": ["Ali", "Omar"], "defenders": ["Lina"]}
print(team["attackers"][0]) # Ali
 
# 3. Dedupe a list using a set, then back to a list
ids = [1, 2, 2, 3, 3, 3]
print(list(set(ids))) # [1, 2, 3]
WHY COMBINE?
📚  List of dicts
A whole dataset — each dict is one record (a row in a table)
🗂️  Dict of lists
Group many values under one key — like teams and players
🪄  Sets for dedupe
set(list) kills duplicates — wrap back in list()
💡  Mental model
List = order · Set = uniqueness · Dict = lookup by key
