💼 Contact Manager
A tiny app that stores contacts with name, phone and tags — powered by lists, dictionaries AND sets together.
⚙️ Features
1️⃣ Add a contact (name + phone + tags)
2️⃣ Search contacts by name
3️⃣ Remove a contact
4️⃣ Show all unique tags — a set does the work
🧠 Skills you'll use
✅ Lists — hold many contacts
✅ Dictionaries — one {"name", "phone", "tags"} per contact
✅ Sets — tags stay unique, zero duplicates
✅ while True menu + input()
✅ f-strings from Session 4
💡 Real-world pattern — phonebooks, CRM systems and the contact list on your phone all work exactly like this.
