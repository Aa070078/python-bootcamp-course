🥞 NESTED DICTIONARIES
Dict Inside a Dict
Values can be lists… and lists can hold dicts. Follow the chain.
القيمة داخل القاموس قد تكون قائمة، والقائمة قد تحتوي قواميس بدورها — نتابع السلسلة مفتاحًا مفتاحًا.
nested.py
classroom = {
    "teacher": "Ms. Sara",
    "students": [
        {"name": "Ahmad", "age": 16},
        {"name": "Layla", "age": 17},
    ],
}
 
print(classroom["teacher"]) # Ms. Sara
print(classroom["students"][0]["name"]) # Ahmad
READ THE CHAIN
classroom["students"]
    → a list of dicts
classroom["students"][0]
    → the 0-th student → a dict
classroom["students"][0]["name"]
    → "Ahmad"
🧭  Navigate left → right
Each [ ] steps one level deeper into the structure
