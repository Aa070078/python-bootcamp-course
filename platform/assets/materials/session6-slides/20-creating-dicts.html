🔧 CREATING DICTIONARIES
Creating a Dictionary
Three ways to build one — { }, dict(), or straight key: value pairs.
إنشاء القواميس: استخدم الأقواس المعقوفة {} أو الدالة dict() أو شكل «المفتاح: القيمة».
dicts.py
# Three ways to create a dictionary
empty = {} # 1. empty braces
d1 = dict() # 2. dict() constructor
 
student = {"name": "Ahmad", "age": 16} # 3. pairs
 
print(student["name"]) # Ahmad
print(student) # {'name': 'Ahmad', 'age': 16}
3 WAYS — SAME RESULT
1️⃣  { }
Empty braces → an empty dictionary
2️⃣  dict()
The constructor — also empty
3️⃣  {key: value}
Pairs separated by commas — keys can be strings or numbers
⚠️  {1, 2, 3} is a SET!
Colon → dict. No colon → set.
