💼 REAL PROBLEM
Clean a messy list in ONE line
Duplicated emails? The set eats them. 🍽️
تنظيف القوائم المكرّرة في سطر واحد — المجموعة تحذف التكرارات
clean.py
emails = ["ali@x.com", "sam@x.com",
                  "ali@x.com", "noor@x.com"]
 
unique = list(set(emails))
 
print(unique)
# ['ali@x.com', 'sam@x.com', 'noor@x.com']
BEFORE 📜 — 4 items, 1 duplicate
ali@x.com · sam@x.com · ali@x.com · noor@x.com
AFTER ✅ — 3 unique
ali@x.com · sam@x.com · noor@x.com
⚠️ Order is not preserved — use sorted() if order matters.
