⚠️ COMMON MISTAKES
Three traps that bite 🪤
أخطاء شائعة يجب تجنّبها عند التعامل مع المجموعات
🔴
{ } is NOT a set — it's a dict!
s = {} # ❌ a dict   ·   s = set() # ✅ an empty set
الأقواس الفارغة تُنشئ قاموسًا وليست مجموعة — استخدم set() للمجموعة الفارغة
🟠
No mutable elements — lists crash!
{[1, 2]} # TypeError: unhashable type: 'list'
لا يمكن وضع قائمة داخل مجموعة — القوائم غير قابلة للتجزئة (unhashable)
🔵
Sets have NO order — don't trust print order!
print({3, 1, 2}) # may show {1, 2, 3} — or not!
المجموعة بلا ترتيب مضمون — لا تعتمد على الترتيب الظاهر في الطباعة
