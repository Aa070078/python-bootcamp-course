Word Frequency Counter
Count how many times each word appears — the classic dict problem.
برمجة مباشرة: عدّاد تكرار الكلمات — نستخدم القاموس لنجعل كل كلمة مفتاحًا وعدد تكرارها قيمة.
THE PLAN — 3 STEPS
1️⃣  Split the text
text.split() → a list of words
2️⃣  Look it up
freq.get(w, 0) → 0 if we've never seen it
3️⃣  Count it
Add 1 and store it back under the word
🤝  Try it yourself
Can you rewrite step 2–3 with an if statement instead?
frequency.py
text = "the cat and the dog and the cat"
words = text.split()
freq = {}
 
for w in words:
    freq[w] = freq.get(w, 0) + 1
 
print(freq)
# {'the': 2, 'cat': 2, 'and': 2, 'dog': 1}
