Is it inside? in / not in
Ask a set "does it contain this?" — it answers in one step. ⚡
check.py
skills = {"python", "sql", "git"}
 
print("python" in skills) # True
print("java" in skills) # False
print("java" not in skills) # True
⚡
Instant check — O(1)
A set answers "is X here?" in one step — even with a million items.
🔍 python → found ✅  ·  java → not here ❌
