Count UNIQUE words in a sentence
عدّ الكلمات الفريدة في جملة — بثلاث خطوات
1️⃣ split() → words list 2️⃣ set(words) → unique 3️⃣ len() → the count
unique_words.py
sentence = "the cat and the dog and the bird"
 
# 1) split the sentence into a list of words
words = sentence.split()
 
# 2) a set drops the duplicates
unique_words = set(words)
 
# 3) count the survivors
print(len(unique_words)) # 5
STEP BY STEP 🔎
words → 8 items
'the' 'cat' 'and' 'the' 'dog' 'and' 'the' 'bird'

set → 5 unique
{'the','cat','and','dog','bird'}

len → 5 ✅
"the" and "and" were repeated — the set kept only one of each.
