🛠️ SET METHODS
add · remove · discard · clear
أضِف، احذف، امسح — تعامل بأمان مع المجموعات
tools.py
tools = {"hammer", "saw"}
 
tools.add("drill") # adds one item
tools.add("drill") # again → no change
tools.remove("saw") # ❌ error if NOT there!
tools.discard("saw") # ✅ safe, no error
tools.clear() # removes everything
print(tools) # set()
📘 Quick reference
add(x) ➕ add one element
remove(x) 🔪 raises KeyError if missing
discard(x) 🛡️ never raises an error
clear() 🧹 empties the set
💡
When unsure if a value exists — discard() is the safe choice.
