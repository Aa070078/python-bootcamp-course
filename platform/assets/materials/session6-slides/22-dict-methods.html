🛠 ADD · UPDATE · DELETE
Changing a Dictionary
Dictionaries are mutable — add, overwrite, or remove keys freely.
القواميس قابلة للتعديل: نضيف المفاتيح، نحدّث قيمها، أو نحذفها تمامًا.
mutate.py
student = {"name": "Ahmad"}
 
student["age"] = 16 # add a new key
student["age"] = 17 # same key, new value → update
student.update({"city": "Amman", "grade": "A"})
 
del student["age"] # delete a key entirely
grade = student.pop("grade", None) # delete + return the value
print(grade) # A
THE TOOLBOX
➕  d[key] = value
Adds a key, or updates it if it already exists
🧰  .update({...})
Adds or updates several keys in one call
✂️  del d[key]
Deletes the key — KeyError if it is missing
🎣  .pop(key)
Deletes the key and hands you its value back
