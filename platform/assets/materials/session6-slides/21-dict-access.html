🔑 ACCESSING VALUES
Getting Values Out
Bracket lookup d["key"] vs the safe .get() method.
الوصول إلى القيم: استخدم d["المفتاح"] أو الطريقة الآمنة d.get() التي لا تُسبب خطأً إذا غاب المفتاح.
access.py
student = {"name": "Ahmad", "age": 16}
 
print(student["name"]) # Ahmad
print(student.get("age")) # 16
 
# print(student["grade"]) # KeyError: 'grade'
print(student.get("grade", "N/A")) # N/A — safe fallback
BRACKETS vs .GET()
⚠️  d["key"]
Fast, but a missing key raises KeyError and crashes the program
🛡️  .get(key)
Returns None if the key is missing — no crash
🎯  .get(key, default)
Your own fallback value when the key is missing
🧠  Rule of thumb
Use [] when the key must exist, .get() when it might not
