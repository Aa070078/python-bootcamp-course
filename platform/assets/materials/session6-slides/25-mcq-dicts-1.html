🎯 QUICK CHECK // DICTS
Which line creates a dictionary?
Four lines of code — only one builds a dict. 💭
أي سطر من الأسطر الأربعة ينشئ قاموسًا (dict)؟ فكّر قبل أن تُجيب.
A {"name": "Ahmad", "age": 16}
key: value pairs inside braces
B ["name", "Ahmad"]
a list of two strings
C ("name", "Ahmad")
a tuple of two strings
D {"Ahmad", 16}
a set — no colon, so not a dict!
🤔 Hint: look for the : colon — it is the heart of every dictionary.
